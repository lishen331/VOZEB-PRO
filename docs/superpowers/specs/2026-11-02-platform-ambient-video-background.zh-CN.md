# 平台背景视频（复用登录页视频）

日期：2026-11-02 · 分支：develop · 先本地验证，用户确认后再提交推送 · 不涉及正式环境

## 对齐结论（2026-11-02）

- 放视频：首页、AI 创作 `/create`、社区、画布/短剧/一键成片列表、作品、资产、提示词、IP 库、教学/课程中心、个人中心、计费。
- 不放：全屏画布、短剧编辑器、短剧实验室项目页、管理后台、`/ui-showcase`。
- 手机端照常播放（登录时已缓存）。只在"减少动效"和"省流量"两种情况下显示静态海报图。
- 原来挡住视频的纯色底改成毛玻璃，和登录页、课程中心的 `gm-glass` 同一套视觉。
- 兜底靠层叠顺序：纯色底 → 海报图 → 视频 → 遮罩 → 毛玻璃组件 → 内容。

## 玻璃一致性的做法

海报帧是人物插画（红发女孩、墓碑、橙色花），直接透出来会和内容抢视线。做法：

- 视频层本身整体模糊一次（约 28px）+ 品牌蓝遮罩，只剩流动的色块和光影。这是全屏只算一次的模糊，代价固定，不随卡片数量增加。
- 所有页面面板（侧栏、输入框卡、作品卡、列表卡）改成半透明 surface。因为背后已经是模糊过的底，半透明面板看起来就是毛玻璃，大面板和小卡片的观感完全一致，不需要每张卡各自 `backdrop-filter`。
- 只有叠在滚动内容上面的元素（吸顶栏、浮层、抽屉）再加 `backdrop-filter`，因为它们背后是清晰的内容，不是模糊底。

## 目标

登录后的平台页面用登录页同一段背景视频（`/login/hero.mp4` + `hero-poster.webp`）做底，登录前后视觉基调一致。视频在平台里只作氛围底纹，不能抢内容、不能影响可读性和性能。

## 现状

- 登录页：`auth-form.tsx` 的 `.auth-education-media` 层 = 海报图 + 视频 + 两层 scrim + aurora 光晕，明暗两套变量 `--ae-*`（`global-auth.css`）。
- 平台外壳：`AppWorkspaceShell` 只有一团 `gm-aurora` 蓝色模糊光，底色 `--gm-bg` 纯色。
- 首页 `/`：`GammaHomeView` 自带外壳，同样是纯色 + `gm-aurora`。
- 44 个页面根节点自己写了 `bg-[var(--gm-bg)]`，会把外壳背景盖掉。

## 设计

### 视觉层次（从下到上）

1. **底色**：`--gm-bg`，视频没加载出来时就是现在的样子。
2. **海报图 / 视频**：`object-fit: cover`，透明度明显低于登录页（浅色约 0.20，深色约 0.30），略降饱和，只留流动的光影质感。
3. **scrim**：比登录页更重。顶部和左侧（侧栏、标题区）压得最实，右下角稍透，形成"边缘有光在动、中心干净"的效果。明暗两套。
4. **品牌光晕**：保留现有 `gm-aurora` 的蓝 + 青两团光，与登录页 aurora 同色系，深色模式用 `screen` 混合。
5. **内容**：页面根节点改透明，卡片、面板、输入框保持原有实底或玻璃底，文字对比度不变。

### 改动范围

- 新组件 `components/gamma-ui/gamma-ambient-backdrop.tsx`：渲染上面 2～4 层，视频地址读站点配置 `loginPage.heroVideoUrl / heroPosterUrl`（与登录页同一来源，后台换了登录视频平台同步换）。
- `AppWorkspaceShell` 和 `GammaHomeView`：用这个组件替换现有的单个 `gm-aurora` div。
- 页面根节点透明：只针对外壳内容区的**直接子元素**，CSS 选择器把 `bg-[var(--gm-bg)]` 改成透明，不碰页面内部用到 `--gm-bg` 的编辑器、输入框等。没被选择器覆盖到的页面保持原纯色底，不会出错，只是看不到视频。
- 侧栏、小屏顶栏：改成半透明 + `backdrop-blur`，让视频从侧栏边缘透出来，保证整页是一张连续的底。

### 不做的地方

- 全屏工作区（`/canvas/:id`、`/drama/:id`、`/drama-lab/:id`）不加视频，这些页面 GPU 和注意力都要留给作品本身。
- 管理后台 `/admin` 不加。
- 不碰 `/ui-showcase`。

### 性能与降级

- 视频文件 9.4MB，与登录页同一 URL，登录时已缓存，进平台基本不再下载。
- 先显示海报图，浏览器空闲后再挂载视频，`canplay` 后 900ms 淡入（与登录页一致）。
- 以下情况只显示海报图、不加载视频：`prefers-reduced-motion`、`navigator.connection.saveData`。
- 标签页切到后台时暂停视频，回来继续。
- 视频层用 `position: fixed` + `pointer-events: none`，不参与布局和滚动重绘；不对视频用 CSS `blur`（全屏模糊开销大），靠透明度和 scrim 做柔化。

## 验证

- `pnpm lint`、`pnpm typecheck`、相关单测。
- 本地 dev server 逐页过一遍：首页、创作、画布列表、短剧列表、资产、作品、提示词、教学/课程中心、个人中心、计费，明暗两种主题各看一次；确认文字可读、无整页闪烁、滚动流畅。
- 打开一个全屏画布确认没有视频层。
- Chrome Performance 看首页 GPU 占用，与改动前对比。

## 回滚

改动集中在新组件、两个外壳和一段 CSS，revert 对应提交即可恢复纯色底。
