# 一键成片一级功能需求与迁移验收规范

## 1. 目标

在 VOZEB-PRO 中新增一级功能“ 一键成片 ”，与“创作工坊”同级。该功能面向教学版本，但业务行为必须等价于已验证的 LocalMiniDrama（L）产品；V 仅负责平台承载、React/Next UI、认证、任务、模型、OSS、计费和画布集成。

## 2. 产品层级与入口

```text
插件市场
├── 创作工坊（既有功能，不改）
└── 一键成片（新增一级插件，可独立启停）

前台侧边栏
├── 创作工坊
└── 一键成片（紧跟创作工坊）
```

- 插件市场新增“一键成片”卡片及总显示开关。
- 开关关闭时，前台侧边栏、首页入口和相关导航不显示；本次不新增服务端业务禁用逻辑。
- 点击“一键成片”进入独立工作区页面，不使用小弹窗，不嵌套到创作工坊页面。
- 既有创作工坊页面、入口、数据和接口保持不变。
- 一键成片页面使用 V 的组件、样式、任务面板和布局；不复制 L 的 Vue 页面。

## 3. 业务不变量

### 3.1 L 逻辑必须等价

L 是行为基准。迁移验收以用户可观察行为、持久化数据、请求载荷和任务状态为准，不以组件数量或字段数量为准。每一项 L 能力都必须有：V 实现位置、服务端接口、持久化字段、自动化测试和手工验证步骤。

### 3.2 画布

一键成片复用 V 平台画布。每集对应一个画布上下文，分镜和资产可定位到画布；不得复制 L 的画布存储或创建第二套画布系统。

### 3.3 任务

所有长任务必须服务端持久化，前端可查看状态、取消、重试和恢复。刷新页面不丢失任务状态；重复点击同一业务任务必须去重或明确提示。不得使用 setTimeout 模拟任务完成。

### 3.4 显示开关

“一键成片”总开关及其后续细分开关只控制前端显示/隐藏。关闭后对应入口或按钮不渲染；不修改 API、计费、任务执行和历史数据。未配置的旧数据默认显示。

## 4. 一键成片完整流程

```text
新建项目/导入 TXT、MD
→ 章节识别与分集草稿
→ 选择/编辑集数
→ 剧本生成与保存（支持多集、增量、恢复）
→ 角色/场景/道具提取
→ 资产描述格式化与参考图管理
→ 分镜拆解（真实 sceneId/characterIds/propIds）
→ 经典/首尾帧/全能模式
→ 分镜图生成或上传
→ 分镜视频生成或上传
→ 对白/旁白配音与按音频拆镜
→ 批量任务编排、状态、取消、重试、恢复
→ 内容审核/团队审批状态
→ 使用 V 画布查看与定位
→ 成片合成与项目导出
```

## 5. L 故事板迁移范围

必须逐项复核并迁移：

- 故事板生成入口、数量/总时长约束、经典/首尾帧/全能模式。
- 分镜完整字段：标题、描述、主体动作、场景空间、景别、机位、构图、镜头运动、灯光、景深、段落、对白、旁白、结果、时长、提示词、引用资产 ID。
- 资产选择器和顺序：场景 → 角色 → 道具；只允许项目内真实资产 ID。
- 图片提示词：原始提示词、通用优化、首帧/尾帧、全能提示词的模式差异；最终请求载荷与 L 等价。
- 视频提示词、参考图、首尾帧连续性和状态回写。
- 生成、上传、历史候选、设置主参考图、替换与恢复。
- 提示词编辑弹窗、生成/润色、保存和取消。
- 配音、对白/旁白、TTS、音频拆镜。
- 批量任务、增量保存、截断续写、部分结果恢复、取消、重试和刷新恢复。
- 完整项目导入导出、分镜表和字幕导出。

## 6. 教学版本 UI 要求

- 使用 V 现有设计系统和组件。
- 保留 L 的业务顺序和交互语义，不把复杂流程压缩成静态卡片。
- 教学使用场景下，任务状态、当前步骤、错误原因、重试/取消入口必须可见。
- 每集独立上下文；切换集数不丢失当前任务和草稿。
- 所有核心按钮必须有可定位的 `aria-label`/测试 ID。

## 7. 验收门槛

### P0：不得只有壳子

- 能创建/导入真实项目和多集剧本。
- 能服务端持久化并恢复剧本、资产、分镜和任务。
- 分镜 JSON 具备真实资产 ID 关联并可回读。
- 图片/视频请求载荷、参考图顺序和提示词字段与 L 对齐。
- 刷新、取消、失败、重试、恢复均有真实状态。

### P1：完整业务等价

- 首尾帧连续性、全能模式、音频拆镜、TTS 和批量编排可用。
- V 画布定位可回到对应集/分镜/资产。
- 审核和导出链路具备真实持久化结果。

### P2：教学体验

- 步骤导航、引导文案、空状态、错误恢复、任务历史和可视化进度完整。

## 8. 禁止事项

- 不修改创作工坊既有业务以“腾出入口”。
- 不复制 L 的数据库、画布、认证或模型渠道。
- 不用前端 setTimeout 假装异步任务。
- 不用名称猜资产 ID，不生成幽灵资产。
- 不在未有请求载荷、持久化和测试证据时宣称迁移完成。

## 9. 产品定位硬约束

### 9.1 创作工坊：教学版

现有创作工坊定位为教学版本，保留现有教学工作流、教学引导、阶段入口和前端显示配置。本次一键成片迁移不得修改创作工坊既有业务、字段、请求和任务行为。

### 9.2 一键成片：商单生产版

一键成片定位为面向商单生产的正式工具，与创作工坊同级，不是创作工坊的子功能，也不是教学流程的简化版。它必须以 LocalMiniDrama 为生产行为基准，对 L 的业务逻辑做 1:1 完整复刻。

“1:1”指同一输入下，以下可观察结果和中间状态等价：

- 分集拆解、剧本保存、增量结果和恢复位置；
- 角色、场景、道具字段、关联和真实资产 ID；
- 分镜字段、模式、帧状态、提示词字段和参考图顺序；
- 图片、视频、音频最终请求的字段语义与资源顺序；
- 任务创建、排队、运行、部分完成、成功、失败、取消、重试、恢复和去重；
- 错误分类、可重试边界、用户可见状态和持久化回写；
- 审核、导出、画布定位和最终成片产出。

V 只替换承载层：React/Next UI、V 画布、V 登录权限、V 模型渠道、V 任务基础设施、V OSS、V 计费和 V 数据访问适配器。不得以 UI 简化、字段删减、前端拼接或假任务替代 L 的业务逻辑。

### 9.3 生产版验收原则

未完成 L/V 差异矩阵、请求载荷对比、数据库回写对比、任务状态对比和同输入回归测试前，不得报告“一键成片完成”，也不得把教学版现有功能当作商单生产版已经迁移。

## 9. 产品定位硬约束

创作工坊是教学版，保留既有教学业务；一键成片是面向商单生产的一级功能，与创作工坊同级、独立工作区。

一键成片必须以 LocalMiniDrama 为生产基准做 1:1 完整复刻。同一输入下，分集结果、资产字段与真实 ID、分镜字段与模式、提示词与参考图顺序、图片/视频/音频请求、任务状态（排队/运行/部分完成/成功/失败/取消/重试/恢复/去重）、错误与持久化回写、审核导出和成片结果都必须行为等价。

V 只替换 React/Next UI、V 画布、登录权限、模型渠道、任务基础设施、OSS、计费和数据访问适配器；不得删字段、简化状态机、改写请求语义或用假任务替代。

未完成差异矩阵、请求载荷/回写/状态对比和同输入回归测试，不得宣称完成。
