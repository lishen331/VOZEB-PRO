# 无限练习：Canvas 四项图像工具独立化开发方案

日期：2026-11-18
状态：实施中（按本文方案开发；不触碰 Canvas 既有默认设置与语义）

## 目标

把画布已有的「反推提示词、局部编辑、表情参考、超分放大」作为四个独立练习入口放入无限练习。学生无需创建/打开画布即可完成输入、处理、查看结果、再次调整；成功结果默认保留在当前练习页面，是否保存到个人素材库由学生主动决定。

## 现状与关键边界

- 无限练习首页在 `web/src/app/(user)/practice/components/practice-home.tsx`，现有单项工具卡 `PRACTICE_TOOL_ENTRIES` 只有 3D 导演台。
- Canvas 工具入口定义在 `web/src/app/(user)/canvas/components/canvas-image-toolbar-tools.tsx`。
- Canvas 回调集中在 `web/src/app/(user)/canvas/[id]/use-canvas-node-media-actions.tsx`。反推提示词的 Canvas 行为是创建文本节点和配置节点；局部编辑是蒙版编辑图像任务；表情参考是以源图为 reference 的图像编辑任务；超分放大当前是本地图片处理 `upscaleDataUrl` 后上传，不应误认为 AI 生图。
- 无限练习 API 的 `practice_sessions` 模块约束及 `PracticeModuleKind` 不包含通用图像工具；`storyboard-image` 会尝试绑定工作流，不适合作为无工作流图像编辑工具的伪装模块。不能为了复用而错误复用分镜工作流。
- 图像/文本任务接口已有执行配置、路由、费用记录等底层；练习任务需要服务器侧确认当前用户权限、使用练习模型池、固定 `open-source-practice` profile，不能由客户端自行伪造生产/练习上下文。
- 生成结果保存到个人素材库使用现有 `/api/library-assets` 能力，必须由用户点击触发；源图上传到任务所需的对象存储不等同于将其收入个人素材库。

## 产品与交互

### 首页入口

在既有「单项练习/本地工具」卡片区加入四张独立卡片，分别进入：

- `/practice/reverse-prompt`
- `/practice/local-edit`
- `/practice/expression-reference`
- `/practice/super-resolution`

卡片描述说明输入与结果，不把四项合并成画布或多步骤节点图。点击返回可回无限练习。

### 共用工作台

四个路由复用一个有严格 `toolId` 判别的图像工具工作台，共用上传/素材选择、任务状态、结果预览、错误与诊断区、重试、结果下载、可选保存按钮；每个工具仅呈现自己的字段。

- **反推提示词**：单张输入图；选择分析方向（至少通用描述/主体与风格）；调用视觉理解/文本模型；结果为可编辑提示词文本，支持复制和基于编辑后的提示词再次分析。若当前配置不支持带图理解，明确返回模型/能力错误，不静默改用别的模型。
- **局部编辑**：单张输入图；画布式涂抹蒙版、清除/重置蒙版、文字说明；把原图、蒙版和提示词作为一次图像编辑任务输入。预览新图并允许修改提示词/蒙版重试。
- **表情参考**：单张含人脸图片；通过现有表情编辑参数/预设构建提示词，支持目标表情和强度；提交图像编辑，显示并可重试。
- **超分放大**：单张输入图；使用现有 `upscaleDataUrl` 算法和倍率参数本地处理，明确标记为本地处理，不调用 AI、不扣模型积分；展示原图/结果对比。结果上传对象存储供预览/下载，但不自动建个人素材记录。

### 结果与保存

- 结果在当前工作台内保留，失败不清空输入、参数或已有结果。
- 只有成功结果显示「保存到个人素材库」；默认不保存。保存成功后显示“已保存”，防重复提交；保存失败保留结果并允许重试。
- 用户主动选择的源素材可从本地上传或素材库选择；素材库选择不复制或修改原资产。

### 费用与执行策略

- AI 任务在提交前说明当前工具会调用 AI；服务端以无限练习模型配置/逻辑模型池解析模型，并按现有图像/文本生成任务进行积分和费用处理。
- 超分放大是本地变换，应标为“本地处理 / 不消耗 AI 模型积分”，仍受上传和存储限制。
- 不回退生产模型，不做跨模型隐式重试。所选能力/路由不支持输入时，返回可诊断的明确错误。

## 技术方案

1. **隔离式路由适配**：四个 URL 都提供 server page 完成登录/练习权限校验，再加载共享 `PracticeImageToolWorkbench`，使用枚举 `PracticeImageToolId` 约束工具类型；不将入口塞进 Canvas 路由。
2. **独立任务代理 API**：新增练习图像工具任务端点，服务端从已登录用户和练习配置读取模型/执行 profile；按工具类型固定可调用能力（反推=文本视觉分析；局部编辑/表情=图像编辑；超分=不走该 API）。复用现有 task route 内部协议/工具函数，避免客户端可伪造 `executionProfile` 或选用生产渠道。
3. **输入引用**：上传图片用现有 image-storage 上传；图像任务通过服务端验证的上传 URL/引用输入，不将源图自动写入个人素材库。局部编辑的蒙版作为 image task `mask` 传递。
4. **结果状态**：工作台保留任务输入、参数、成功结果、任务 ID/模型与失败原因于组件状态；再次生成只替换当前工具结果，保留历史结果的最低要求是当前页面不因失败丢失上一次成功结果。此首版不新增无限练习会话表/模块类型，AI 执行仍进入现有生成任务与计费日志。
5. **Canvas 不变**：复用现有纯函数/图像处理算法和对话框参数，不直接调用 Canvas node callbacks，也不改快捷工具默认可见项、节点/连线行为。

## 安全与错误诊断

- Server page 与 API 均进行登录和无限练习权限校验。
- API 端仅接受白名单工具 ID、合法 mime、大小限制内的已上传图片引用、有效提示词/参数；模型 ID 不接受客户端任意传入。
- 请求上下文通过服务端验证并携带练习执行 profile，生产模型池不可达。
- 错误区提供用户可读错误、任务 ID、工具名、模型 ID（如服务端已解析）和可复制诊断 JSON；不暴露密钥、上游授权头或敏感内部 URL。

## 验收标准

1. 无限练习首页显示四张独立卡片，分别落到目标 URL；登录/练习权限拒绝时不可绕过。
2. 反推提示词真实提交单图分析并呈现可编辑文本；不支持视觉输入时明示失败。
3. 局部编辑支持上传/选图、绘制/清空蒙版、提示词、生成、失败后保持状态及成功图预览。
4. 表情参考支持源图与表情/强度配置，并显示实际编辑结果。
5. 超分放大调用 Canvas 同一算法，不创建 AI 生成任务、不扣 AI 积分；结果可预览/下载。
6. 四种结果都不会自动进入个人素材库；点保存后仅将当前生成结果保存一次，保存失败可以重试。
7. AI 工具只走练习模型池和现有积分任务路由，禁用生产回退；API 校验未授权、非法类型/参数和过大输入。
8. Canvas 四项工具原入口、默认快捷工具设置、画布节点和连线语义均保持不变。
9. 相关单测、lint/typecheck 与生产构建通过；桌面/移动布局与暗色主题无溢出。

## 不在本次范围

- 修改 Canvas 工具或默认工具栏配置。
- 新增后台模块开关、数据库练习模块/会话表结构。
- 自动保存源图/结果到个人素材库。
- 四工具之外的裁剪、消背景、分层等 Canvas 工具。
- 多次结果的云端练习历史列表（当前工作台保留结果，刷新后的历史持久化另行设计）。
