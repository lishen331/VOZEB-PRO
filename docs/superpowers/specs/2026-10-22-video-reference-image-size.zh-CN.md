# 视频参考图尺寸不满足 300–6000 像素时自动等比调整

## 问题

2026-10-22 生产有 27 条画布视频任务失败，报错 `Height must be between 300px and 6000px` / `素材尺寸不符合要求，宽度和高度需在 300 至 6000 像素之间`，模型为 `cdance2.0-0807`、`doubao-seedance-2-0`。

只读核查（生产库）：

- 27 条全部来自同一画布 `canvas-0Rq1x4XbOeRqvNGKc5Zyt` 的 4 个视频节点。
- 每个节点都挂了 3 张用户上传的截图：444×283、499×280、511×281，高度都不到 300。
- 平台生成的图（1824×1024、1600×898）全部合格。生图尺寸不是原因。

## 改动

1. `web/src/lib/video-reference-size.ts`：定义 300 / 6000 两个边界，提供 `fitVideoReferenceSize`（返回等比后的目标宽高；无需调整返回 `null`；比例超过 20:1 返回 `"impossible"`），以及 `videoReferenceSizeIssues`（按"图片N"序号列出不合格的图）。
2. `web/src/lib/server/video-reference-image.ts`：每张参考图都读取真实字节和 EXIF 方向后的宽高。
   - 在范围内且是 PNG/JPEG：原样提交（与之前一致，只多了一次读取）。
   - 不在范围内：等比放大或缩小到边界内，另存一张 PNG 临时引用后提交，原图不动。
   - 比例超过 20:1：返回 400，提示先裁剪。
3. 画布视频生成（`use-canvas-generation-actions.tsx`，含短剧画布运行时副本）：提交前检查参考图宽高。
   - 有不合格的图时弹确认框，逐张列出"图片N：原尺寸 → 目标尺寸（放大/缩小）"，并说明放大会降低清晰度。用户点"继续生成"才提交，点"取消"不扣费、不建节点。
   - 比例超过 20:1 时直接拦截并提示裁剪。
4. 画布视频参数面板（`canvas-video-reference-settings.tsx`）：已连接的图有不合格尺寸时，显示黄框提醒。
5. `generation-feedback-message.ts`：上游仍以尺寸原因拒绝时，提示"参考图尺寸不符合要求（每边需 300–6000 像素），请更换更清晰的图片后重试"，不再显示"网络异常"。

## 规则调整

`AGENTS.md` 原规定视频参考图只能做无缩放的格式转换。现补充一条唯一例外：不满足 300–6000 时允许等比缩放，且前端必须先让用户确认。

## 不在本次范围

- 画布"失败后重试"走保存的引用快照，不会再弹确认框，但服务端仍会自动调整尺寸，所以重试同样能成功。
- 创作工作台和短剧工作台的视频入口没有加确认框，服务端会自动调整尺寸。

## 验证

- 单测：`video-reference-size.test.ts`（放大、缩小、范围内不动、20:1 拦截、序号）；`video-reference-image.test.ts`（444×283 → 471×300、范围内零拷贝、WebP 转 PNG）；`generation-feedback-message.test.ts`（三种上游报错映射）。
- 类型检查、相关 vitest。
