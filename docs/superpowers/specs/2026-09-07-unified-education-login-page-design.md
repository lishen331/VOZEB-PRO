# 统一教学平台登录页设计

## 1. 文档状态

- 状态：已确认
- 确认日期：2026-09-07
- 设计对象：VOZEB PRO / BLUEGAMMA 登录页
- 当前页面：[https://reddetail.gammablue-x.com/login](https://reddetail.gammablue-x.com/login)
- 目标参考页：[https://edu.bluegamma-gd.com/login/pwd-login](https://edu.bluegamma-gd.com/login/pwd-login)

本设计仅以参考页的页面结构、品牌排布、视觉比例和信息层级作为目标，不复制参考站源码，也不使用参考站未由项目方提供的图片、字体或其他素材。

## 1.1 2026-09-08 需求变更

用户明确要求登录页不再展示“立即注册”和“忘记密码”，并禁止普通用户自助注册。该变更覆盖本文后续关于保留注册、找回入口和开放注册开关的旧决策：

- 登录页不得渲染“立即注册”“忘记密码”及其引导文案。
- `/register` 在安装完成后返回登录页；`POST /api/auth/register` 在安装完成后固定拒绝公开注册。
- 首个管理员安装流程和管理员后台创建账号继续保留。
- 图形验证码仍不实现，管理员 MFA、登录限流和登录审计保持不变。

## 2. 已确认决策

1. 所有需要登录的入口统一进入新版独立 `/login` 页面，不再弹出首页双栏登录 Modal。
2. 平台管理员、老师和学生共用同一个登录页面，不提供“选择身份”按钮或下拉框。
3. 老师和学生在没有明确返回目标时，登录后统一进入创作 Agent `/create`。
4. 平台管理员在没有明确返回目标时，登录后进入 `/admin`。
5. 从受保护页面进入登录页时，登录成功后优先返回原目标；账号无权访问该目标时，再进入对应角色的默认页面。
6. 页面整体布局和联合品牌展示按目标参考页对齐。
7. 桌面左侧使用 `C:\Users\admin123\Desktop\物料\完整.mp4` 作为主视觉视频。
8. 视频静音、自动播放、循环播放、内联播放，不显示播放器控件；视频不可播放时显示静态封面。
9. 不使用图形验证码或滑块验证码。
10. 保留“立即注册”和“忘记密码”。
11. 保留平台现有登录限流、失败审计、账号状态校验和平台管理员 MFA；管理员动态码不属于图形验证码。
12. 注册页和忘记密码页第一版不随登录页一起重做，只保留正确入口和返回关系。

## 3. 目标与边界

### 3.1 目标

- 将当前居中卡片式登录页改为与参考页一致的全屏左右分栏教学平台登录页。
- 统一首页、会话过期、受保护页面和其他未登录入口的登录体验。
- 使用正式联合品牌和教学平台文案，替代当前偏创作工具的登录文案。
- 允许平台管理员在后台更新登录页视频、封面、联合品牌图、标题和页脚信息。
- 保持既有账号密码认证、注册、密码找回、MFA、安全审计和 Session 能力。

### 3.2 不做

- 不创建平台管理员、老师、学生三套登录页。
- 不让用户在登录前自行选择角色。
- 不复制参考站验证码。
- 不新增短信登录、扫码登录、第三方 OAuth 或“记住密码”。
- 不把登录页做成自由拖拽的页面搭建器。
- 不允许后台配置任意布局比例、按钮样式、间距或 CSS。
- 不在登录页展示首页导航、主题切换、返回首页按钮或创作功能介绍卡片。
- 不改变首个管理员初始化 `/install` 的既有契约。

## 4. 页面结构

### 4.1 桌面端

宽度达到桌面断点时，页面占满可视区域并采用接近参考页的 50% / 50% 左右分栏：

#### 左侧主视觉区

- 视频铺满左侧区域，使用 `object-fit: cover`，焦点默认居中。
- 不叠加标题、按钮、渐变文案或播放器控制条。
- 视频加载前显示静态封面；加载失败、格式不支持或自动播放被阻止时继续显示封面。
- 用户启用“减少动态效果”时不自动播放，直接显示封面。

#### 右侧登录区

内容按参考页纵向排列：

1. 顶部横向联合品牌图。
2. 主宣传语：`以热爱，燃未来`。
3. 平台名称：`AIGC 智能影像教学平台`。
4. 用户名或邮箱输入框。
5. 密码输入框和显隐按钮。
6. `登录`主按钮。
7. 用户协议和隐私政策确认区。
8. `立即注册 / 忘记密码`辅助入口。
9. 页面底部的版权、运营单位、客服电话和工作时间。

右侧表单保持单列，输入框与主按钮等宽。登录区使用固定的品牌浅色背景，不跟随应用深色主题切换；登录成功进入应用后恢复用户或系统主题。

### 4.2 移动端与窄屏

- 390px、430px 等窄屏不显示占据半屏的大视频区域，避免首屏只看到主视觉而看不到登录表单。
- 静态封面可作为页面顶部的紧凑品牌背景，但不能挤压联合品牌和表单。
- 联合品牌图、宣传语、平台名称、账号密码和登录按钮必须在首屏形成完整操作路径。
- 页脚信息可以自然位于表单下方，不固定遮挡内容。
- 页面和内部容器不得横向溢出。

## 6. 登录表单与安全规则

### 6.1 通用字段

- 用户名或邮箱。
- 密码。
- 密码显隐按钮。
- 用户协议和隐私政策确认。
- 登录按钮。
- 立即注册。
- 忘记密码。

登录页不显示图形验证码。登录接口继续执行现有速率限制、失败审计和账号状态判断，不能因为取消验证码而移除安全保护。

### 6.2 协议确认

- 按参考页显示协议确认控件和说明。
- 未确认协议时登录按钮不可提交。
- 协议链接继续复用站点配置中的 `termsUrl` 和 `privacyUrl`。
- 协议链接在新页面打开，不能导致已填写的用户名丢失。

### 6.3 管理员 MFA

- 普通密码提交后，如果服务器返回管理员 MFA 挑战，仍在右侧登录区内显示动态码输入。
- MFA 阶段保留用户名，不要求重新输入密码。
- MFA 成功后继续执行原目标或角色默认跳转。
- 页面不得将 MFA 文案写成图形验证码。

### 6.4 注册与找回密码

- 站点允许公开注册时显示“立即注册”，进入现有 `/register`。
- 站点关闭公开注册时不展示一个无法完成的注册入口。
- “忘记密码”继续进入 `/forgot-password`。
- 从登录页进入注册或找回密码时保留安全的 `next` 目标；流程结束后可返回登录页并继续原目标。
- 公开注册不能选择注册为平台管理员。老师和学生身份继续由学校成员关系决定。

## 7. 三角色识别与登录后跳转

登录前不判断角色，服务器完成账号认证后再根据账号与学校成员关系决定权限。

### 7.1 跳转优先级

1. 存在合法的站内 `next` 目标且当前账号有权访问：返回该目标。
2. `next` 目标无权访问：进入该账号的默认页面，并显示普通权限提示。
3. 没有 `next`：平台管理员进入 `/admin`；老师和学生进入 `/create`。

### 7.2 角色矩阵

| 身份 | 登录页面 | 无 `next` 默认入口 | 说明 |
| --- | --- | --- | --- |
| 平台管理员 | 统一登录页 | `/admin` | 已启用 MFA 时继续完成动态码挑战 |
| 老师 | 统一登录页 | `/create` | 学校教师身份由成员关系识别 |
| 学生 | 统一登录页 | `/create` | 学校学生身份由成员关系识别 |

老师和学生在基础账号中均可能表现为普通用户，因此不能要求用户在表单上选择“老师”或“学生”。

### 7.3 原页面与创作草稿

- 所有受保护入口统一生成 `/login?next=<站内目标>`。
- `next` 只允许单斜杠开头的站内路径，拒绝 `//`、外部协议和其他开放重定向形式。
- 从首页创作输入进入登录时，保留当前 `/create` 哈希草稿和创作类型；登录成功后返回 `/create` 并恢复草稿。
- 登录失败、MFA 挑战或查看协议时不能清空已经填写的用户名。

## 8. 首页及全站登录入口改造

当前首页登录由 `HomeActionsProvider` 打开 `landing-auth-modal`。新版规则是：

- `openLogin(nextPath)` 改为导航到独立登录页，不再维护 `authOpen` 和登录 Modal。
- 首页“立即体验”、Agent 输入、页头受保护导航、页脚受保护导航、价格购买等入口都使用同一跳转方法。
- 其他页面的会话失效和鉴权跳转也必须遵循同一 `next` 契约。
- 删除或停止渲染旧登录 Modal 后，清理只服务于该 Modal 的样式；不能误删注册页、忘记密码页仍使用的认证样式。

## 9. 后台站点配置

在现有站点设置中增加“登录页”分区。第一版固定布局，只允许配置内容：

```text
site.loginPage.heroVideoUrl
site.loginPage.heroPosterUrl
site.loginPage.jointBrandUrl
site.loginPage.slogan
site.loginPage.platformName
site.loginPage.footerOrganization
site.loginPage.servicePhone
site.loginPage.serviceHours
```

### 9.1 字段规则

| 字段 | 默认或行为 |
| --- | --- |
| 主视觉视频 | 初始使用由 `完整.mp4` 转制的浏览器兼容视频 |
| 视频封面 | 初始使用从 `完整.mp4` 导出的代表帧 |
| 联合品牌图 | 初始使用项目方提供的两份品牌物料合成图 |
| 宣传语 | 默认“以热爱，燃未来” |
| 平台名称 | 默认“AIGC 智能影像教学平台” |
| 运营单位 | 可配置；为空时对应页脚片段不显示 |
| 客服电话 | 可配置；为空时不显示，不照抄参考站号码 |
| 工作时间 | 可配置；为空时不显示 |

版权继续复用现有 `site.footerCopyright`，协议继续复用现有 `termsUrl`、`privacyUrl` 及版本字段，不新增重复配置。

### 9.2 配置与上传

- 视频、封面和联合品牌图支持平台媒体上传，也允许经过安全校验的同源路径或 HTTPS 地址。
- 不接受桌面绝对路径、任意脚本 URL 或未验证的数据 URL。
- 后台提供当前物料预览；保存后必须立即刷新公开站点配置。
- `/api/admin/settings` 的保存和重新读取必须绕过短缓存，保证操作后立即可见、服务端已持久化、刷新页面和 API 再读取一致。
- 未登录用户只获取登录页渲染需要的公开字段，不获取后台设置、密钥或内部配置。

## 12. 验收标准

### 12.1 页面和视觉

- 桌面登录页与参考页保持相同的全屏左右分栏、联合品牌、宣传标题、表单和页脚层级。
- 页面不存在当前居中卡片、返回首页按钮和首页登录 Modal。
- 左侧视频静音自动循环，无控件；失败时始终有封面。
- 390px、430px 页面可以在首屏完成登录，且无横向溢出。
- 登录页采用稳定浅色品牌主题，不出现深色模式下品牌图不可读的问题。

### 12.2 功能

- 首页和全站所有登录入口均进入 `/login`，并正确携带站内 `next`。
- 平台管理员、老师、学生使用完全相同的账号密码表单。
- 无 `next` 时，管理员进入 `/admin`，老师和学生进入 `/create`。
- 合法且有权限的 `next` 优先于默认页面。
- 首页 Agent 草稿和创作类型经过登录后仍能恢复。
- 立即注册和忘记密码入口可用；关闭公开注册时不显示无效入口。
- 普通登录无图形验证码；管理员 MFA、登录限流和审计仍有效。

### 12.3 后台配置

- 管理员可上传或更换视频、封面和联合品牌图，并编辑登录页文字和页脚联系信息。
- 保存后当前后台快照、服务端配置、刷新后的登录页及公开配置 API 四处一致。
- 清空可选联系方式后登录页立即移除对应内容，刷新后不恢复。
- 登录页公开接口不泄露后台私密配置。

### 12.4 回归范围

- `/login`：三角色、错误密码、管理员 MFA、合法/非法/无权限 `next`。
- 首页：页头、Hero、页脚、价格入口均不再出现登录 Modal。
- `/register`、`/forgot-password`、`/install`：既有流程未被登录页样式重构破坏。
- 浅色/深色应用主题进入登录页后均呈现统一品牌浅色页；登录后恢复应用主题。
- 桌面、平板、390px、430px、减少动态效果、视频不支持和慢速加载场景。

## 14. 后续实施边界

开发实施必须先完成登录页面和全站入口统一，再增加后台登录页配置，最后执行三角色与响应式回归。实施 Agent 不得扩大到注册页、忘记密码页的视觉重做，也不得移除管理员 MFA、登录限流、登录审计或站内 `next` 安全校验。
