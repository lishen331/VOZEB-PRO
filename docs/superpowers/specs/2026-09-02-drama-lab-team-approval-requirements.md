# 短剧实验室团队协作与审批需求

**状态：需求对齐完成，已实现，待真实环境验收**
**范围：仅限短剧实验室项目协作**
**日期：2026-09-02**

## 一、范围边界

本阶段只实现短剧实验室的项目组协作和真实审批闭环。

不修改以下内容：

- 现有账户、登录和身份体系
- 教师、学生及其他平台模块
- Canvas 功能本身及其既有架构
- AI 生图、生视频等现有异步任务机制

协作流程只依赖现有登录状态和项目内的协作关系，不新增一套用户管理系统。

## 二、项目组与邀请

### 2.1 项目组创建

- 创建短剧项目时自动创建项目组。
- 项目创建者自动成为项目管理员（组长）。
- 一个短剧项目对应一个项目组。

### 2.2 邀请链接与二维码

- 组长可以生成项目邀请链接和二维码。
- 邀请凭证只标识项目，不公开其他账号信息。
- 邀请凭证支持有效期、撤销和重新生成。
- 协作者打开链接或扫描二维码后，登录现有系统并提交加入申请。
- 加入申请必须由组长或有权限的副组长确认后，才能成为项目成员。
- 未确认的申请只能在该项目的待处理列表中查看。

### 2.3 项目内成员搜索

项目需要提供成员搜索，但搜索范围必须严格限制在当前项目：

- 可以搜索当前项目已经加入的成员。
- 可以搜索当前项目的待加入申请。
- 不允许通过项目协作界面检索项目外的其他账号。
- 不返回项目外账号的姓名、头像、邮箱或其他可识别信息。

### 2.4 成员管理与权限

- 组长可以确认或拒绝加入申请。
- 组长可以移除项目成员。
- 普通成员可以主动退出项目。
- 组长退出前必须先转交项目管理员权限。
- 组长可以任命副组长。
- 副组长只能执行被授予的项目管理和审批权限。
- 项目管理员权限转交必须记录操作人和时间。

## 三、审批配置

组长或有审批权限的副组长可以为项目配置需要审批的阶段。候选阶段包括：

- 剧本
- 角色、场景、道具
- 分镜
- 分镜图
- 分镜视频
- 成片导出

每个阶段至少需要保存：

- 是否启用审批
- 审批人范围（组长、指定副组长或全部管理员）
- 是否启用严格模式

严格模式下，前一阶段未通过时，成员不能提交或执行被阻断的后续阶段。非严格模式只记录审批状态，不阻断创作操作。

## 四、审批提交与处理

### 4.1 成员提交

成员提交阶段成果时，服务端创建审批记录，不由前端状态模拟。记录至少包含：

- 项目 ID
- 集数 ID（如适用）
- 审批阶段
- 目标资源类型和资源 ID
- 对应版本 ID 或版本号
- 提交人
- 提交时间
- 当前内容快照或可复现的版本引用
- 审批状态

图片、视频等大文件只保存资源引用，不在审批记录中复制文件。

### 4.2 审批结果

审批人可以：

- 通过
- 驳回并填写意见

建议状态：`pending`、`approved`、`rejected`、`cancelled`。

驳回后成员可以修改并重新提交。重新提交创建新的审批记录，历史记录不可覆盖。

同一审批记录只能被成功处理一次，避免组长和副组长并发操作造成重复结果。

## 五、审批记录定位

审批记录需要保留足以定位内容的上下文：

- 项目
- 集数
- 阶段
- 目标资源 ID

组长点击审批记录后，至少打开短剧实验室对应的集数或功能页面。

如果精确定位到 Canvas 节点的实现成本过高，第一版不要求定位到具体节点，但不能只回到项目首页。

## 六、前端展示与待办

- 保留现有审批 Demo 的交互形式作为 UI 基础。
- 审批状态、意见、历史记录和待处理事项全部读取服务端数据。
- 成员看到自己提交的审批结果和驳回意见。
- 管理员看到项目内待审批列表。
- 使用站内待办或未读数提示。
- 第一版不引入 WebSocket 或即时通讯系统。
- 页面进入时刷新，必要时在审批页面进行低频轮询。

## 七、性能与数据要求

- 邀请、成员和审批均为普通数据库读写。
- 不增加常驻进程或独立后台服务。
- 不改变 AI 生成任务的队列、计费和轮询机制。
- 审批查询建立项目、状态、审批人和创建时间相关索引。
- 审批历史采用分页查询，避免项目规模扩大后一次加载全部记录。

团队审批本身不会成为服务器性能瓶颈，主要资源消耗仍来自 AI 生图、生视频和其他异步生成任务。

## 八、验收标准

1. 项目创建后存在默认组长和项目组。
2. 通过邀请链接或二维码可以提交加入申请。
3. 未经组长确认，申请人不能访问项目内容。
4. 组长可以在项目范围内搜索成员和加入申请，但无法搜索项目外账号。
5. 组长可以移除成员，成员可以主动退出。
6. 组长可以任命副组长并转交管理员权限。
7. 阶段审批配置保存到服务端并可重新加载。
8. 成员提交成果后生成真实审批记录。
9. 通过、驳回、意见和历史记录在刷新后仍然存在。
10. 驳回后重新提交会生成新的审批版本。
11. 点击审批记录可以进入对应短剧实验室页面或集数。
12. 严格模式按配置阻断后续阶段，非严格模式不阻断创作。
13. 审批流程不影响现有 Canvas 和 AI 生成任务。
