# 短剧工作流 Demo 交付说明

## 已完成的三个前端 Demo

### 一键全流程

- 支持选择生成到资产、分镜图或完整视频。
- 支持当前集/全部剧集、画面比例、单镜头时长、输出语言、视觉风格和自动导出的展示配置。
- 展示从提示词到生图、生视频、内容审核和可选导出的执行预览及模拟状态。
- 默认说明使用后台渠道，并在执行完成后保留失败汇总的产品入口。

### AI 内容审核

- 位于镜头生成之后、成片导出之前。
- 展示剧本、资产、分镜图、镜头视频四类审核覆盖范围、综合评分、分项评分和可定位回制作阶段的问题。
- 审核与团队审批是两条独立链路，不混用状态或名称。

### 团队协作与审批

- 制作工作台右侧提供与左侧“剧集”对称的可收起协同面板；窄屏通过右侧 Drawer 访问。
- 演示项目组、成员职责、团队开关、严格审批/并行协作两种模式和五类候选审批节点。
- 项目组长可在 Demo 中开关剧本、资产提示词、视觉图片、分镜视频、成片审核节点。
- 各阶段可模拟提交、通过、打回、修改后重提；并行模式下，上游打回会将已有下游提交标记为“需确认版本”。
- 可模拟配置打回反馈是否必填、是否提醒成员、是否允许附件，并展示反馈记录。
- 严格模式下，上游必审节点未通过时，下游不能提交；一键全流程不能跨越未通过的必审节点；必审节点未全部通过时，成片导出按钮保持限制。

## 当前刻意未实现的真实业务

1. 不创建或保存项目组、成员、职责、审批节点、反馈、附件和通知。
2. 不读取教师、学生、项目组长或普通用户的真实身份，不进行角色权限校验。
3. 不保存审批提交的不可变版本快照、依赖版本或旧版本确认记录。
4. 不在服务端实施严格审批门禁、并行模式下的下游版本失效标记或导出授权。
5. 不发送站内信、邮件、`@成员`提醒，不提供截止时间、任务分配或任务看板。
6. 不调用真实 AI 内容审核模型，不保存审核结果、评分、风险项或扣费流水。
7. 一键全流程不创建真实提示词、图片、视频或导出任务，不保存配置，也不消耗渠道额度。

## 真实业务实现顺序

1. 建立项目组、成员、职责、项目协作规则和审批节点的服务端数据模型，并接入统一 VOZEB PRO 账号。
2. 为每次提交保存不可变成果快照及其上游版本依赖，提供成员可见的审批时间线。
3. 在服务端实施严格模式门禁、并行模式的旧版本确认和全部必审节点通过后的导出授权。
4. 接入项目组长、成员、教师/学生附带身份和普通 C 端邀请协作者的真实授权规则。
5. 接入反馈、通知、附件、`@成员`和可选的截止时间/任务管理能力。
6. 接入 AI 内容审核执行、风险与质量评分、问题定位和可选的项目级导出门槛。
7. 将一键全流程接入真实 Agent 编排、生成任务、失败汇总、重试、成本和额度管理。

## 验收重点

- 桌面端右侧面板展开/收起不挤压或遮挡中央制作区；窄屏 Drawer 可完整滚动。
- 严格模式应阻止跨越未通过的上游必审节点；并行模式允许继续制作但保留“需确认版本”提示。
- 禁用某审批节点后，该节点不再形成提交或导出门禁。
- 全部已启用节点通过后，导出按钮的审批限制解除，但不会自动执行导出。
- AI 内容审核页面不改变团队审批状态，团队审批操作也不改变 AI 审核报告。
