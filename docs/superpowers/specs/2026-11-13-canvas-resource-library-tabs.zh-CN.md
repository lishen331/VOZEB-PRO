# 画布资源栏分类合并开发说明

日期：2026-11-13

范围：Canvas 左侧「资源」侧栏 UI；复用现有素材、公共作品和提示词接口，不改 API、数据库、生成流程。

## 目标

让用户在画布资源侧栏中更直观地区分个人资源和共享资源，并将个人提示词与公共词库放在同一入口内切换，减少顶部并列标签。

## 导航与交互

- 顶层入口调整为「当前」「素材」「提示词」；启用现有 IP 功能时仍显示「IP」入口。
- 进入「素材」后显示同一侧栏内的二级切换：「我的素材」「公共素材」。
  - 「我的素材」沿用现有素材库分页、搜索、类型筛选、预览和插入行为。
  - 「公共素材」复用现有公开作品列表及公开作品详情 API，仅展示公开作品内可访问的图片、视频、音频内容素材；支持类型筛选、搜索、预览、分页和插入画布。
  - 公共素材插入只在当前画布创建引用节点，不复制进个人素材库，不改变公开作品或原始媒体。
- 进入「提示词」后显示同一侧栏内的二级切换：「我的提示词」「词库」。二者继续复用各自既有查询、分类、搜索、分页、封面预览和插入提示词行为。
- 二级切换保留各自的搜索词、筛选项和已加载状态；首次切入时再加载数据；用户切换账号时继续清空缓存并重新取数。
- 关闭侧栏或切换项目不变更现有业务数据和调用契约。

## 视觉与响应式

- 保持现有侧栏尺寸、主题色、暗色/亮色适配和移动端 Drawer 行为。
- 二级切换紧随顶层标签下方，视觉上作为当前区域内部 tabs；可读、可点击，不新增弹窗。
- 维持原有列表网格、搜索/筛选区域、加载/错误/空状态。

## 验收条件

1. 顶部不再出现单独的「词库」顶层按钮；有「当前、素材、提示词」，IP 开关开启时另保留 IP。
2. 「素材」下能切换「我的素材 / 公共素材」，个人素材接口和已有操作不回归。
3. 公共素材只从已公开作品内容媒体加载，可预览并插入对应类型画布节点；不可插入封面图，不复制或修改公开/个人素材数据。
4. 「提示词」下能切换「我的提示词 / 词库」，两套原有查询、筛选、插入能力完整保留。
5. 搜索/筛选切换后不会展示旧请求覆盖的新结果；用户变化时请求和列表缓存正确失效。
6. 桌面侧栏与移动端 Drawer 无溢出、无横向滚动，所有标签可操作且有无障碍 role/label。
7. 专项 Vitest、TypeScript、ESLint、Prettier、开发地图/接口索引验证、浏览器回归通过后才推送 `origin/develop`；只部署共享测试环境，不发布生产。

## Canvas 侧栏缩略图加载

- 「我的素材」「公共素材」「我的提示词」「词库」列表都是单页有限数量的缩略图；图片卡片在侧栏中使用 eager 加载，避免浏览器对嵌套滚动区域的原生 lazy 图片不触发请求，导致可见缩略图停留在占位状态。
- 「当前」列表可能包含大量画布节点，仍保留 lazy 加载，避免一次性请求全部历史节点图片。
- 验收用真实 Chromium 检查上述三个资源来源的可见 `<img>` 为 eager，并确认图片 `naturalWidth > 0`；同时确认 390px 侧栏没有横向溢出。

## 明确不包含

- 不改公共素材或提示词的发布/管理权限。
- 不新增数据库表、字段、API 或后台配置。
- 不把公共素材自动保存到用户素材库。
- 不改 Canvas 节点结构、创建方式、媒体生成或计费。
