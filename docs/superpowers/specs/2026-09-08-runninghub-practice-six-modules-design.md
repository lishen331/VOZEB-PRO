# 无限练习六模块与 RunningHub 工作流对齐设计

## 目标

将无限练习收敛为 Demo 已验证的六个业务入口，并准确绑定七条 RunningHub 工作流；保留现有提示词、尺寸、素材、音频开关和其他运行入参。后台可以逐项隐藏无限练习入口，工作流测试从硬门禁改为风险提示。

## 页面结构

无限练习首页按卡片顺序展示：角色、场景、道具、分镜图、分镜视频、音频。角色页面内部保留主视图与多视图切换，分别使用 `character_main_view` 与 `character_multi_view`。其余入口依次使用 `scene_main_view`、`prop_main_view`、`storyboard_shot`、`storyboard_shot_video`、`storyboard_dialogue_audio`。

无限画布与无限短剧默认隐藏；剧本和音乐不再作为六模块首页入口。现有表单字段、提示词生成和任务结果区不改语义。

## 配置与可用性

后台新增无限练习入口显示设置，支持单独控制无限画布、无限短剧和六个业务模块。隐藏项不在首页显示，六个业务模块的能力接口也不返回隐藏项。

历史上已经启用并测试成功的 RunningHub 工作流在设置读取时自动派生内部模型、渠道模型配置和练习绑定，不要求重新启用。工作流启用时仍持久化同一派生结果。

## 测试门禁

测试成功继续作为“已验证”证据，但不再阻止启用。未测试、测试失败或配置变更后启用时，管理员界面显示风险确认；服务端允许启用配置完整的工作流。输出映射、节点映射等结构校验仍保留。

## 验收

- 无限练习首页只有六个业务卡片，顺序与 Demo 一致。
- 角色页可选择主视图/多视图，七条工作流映射明确。
- 后台可逐项隐藏入口，默认隐藏无限画布和无限短剧。
- 历史已启用工作流刷新后可直接形成前端模型。
- 未测试工作流经风险确认后可启用。
