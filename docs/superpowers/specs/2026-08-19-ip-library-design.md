# IP 库设计

## 1. 背景与目标

平台需要把已经线下审核通过的 IP 内容整理成可授权的内容包，分配给学校用于 Canvas、短剧、无限练习和学校线下创作。IP 库不是普通素材库，也不是线上投稿社区；它负责组织 IP 的文本、图片、音乐、声音和视频参考，并记录学校授权、版本和使用关系。

第一期目标是让平台管理员可以创建和发布 IP、授权给学校，学校成员可以查看、引用、下载和线下使用；不建设线上版权方投稿、作品公开发布限制、商单使用限制或线上结算。

## 2. 已确认的产品决策

### 2.1 前端入口

IP 库位于用户端：

```text
社区
└─ IP库
   ├─ 公共 IP
   └─ 本校 IP
```

前端不单独展示“多校授权 IP”目录。学校 IP 卡片只显示“本校 IP”；如果当前学校获得的是独家授权，再额外显示“独家授权”标签。多校授权信息只在平台管理员后台展示。

### 2.2 访问范围

- 公共 IP：所有已登录用户可以查看、使用和下载。
- 本校 IP：只有当前学校 active teacher、active student 和学校管理员（teacher + school.manage）可以查看、使用和下载。
- 学校之间不能读取、搜索或下载对方的本校 IP。
- 没有学校成员身份的普通 C 端用户不显示本校 IP；直接请求学校 IP 详情、媒体或下载接口返回 403/404。
- 平台管理员的 `admin` 身份不自动等于学校成员；管理员后台管理 IP 不代表管理员可以通过用户端绕过学校授权。

### 2.3 授权模式

授权模式与“公共/本校”展示范围分开：

- `multi_school`：同一 IP 可以同时授权给多个学校。
- `exclusive`：同一有效授权期内只允许一所学校获得授权。
- 公共 IP 不需要学校授权模式。

独家授权生效时，后台不能再创建其他学校的有效授权。多校授权信息不出现在用户端。

### 2.4 内容录入与审核

IP 由平台线下提交和审核，线上不提供版权方、创作者或学校投稿流程。审核完成后由平台管理员后台创建、编辑和发布 IP。学校和普通用户只有查看、使用和下载权限。

### 2.5 版本

IP 采用不可变发布版本：

```text
IP
├─ v1 已发布
├─ v2 已发布
└─ v3 草稿
```

编辑已发布 IP 时创建新的草稿版本，发布后形成新的版本号。新引用和新下载默认使用最新发布版本；历史使用、下载、Canvas、短剧和练习记录固定保存 `ipVersionId`。旧版本保留为只读追溯记录，不因新版本发布而被覆盖。

### 2.6 下载与线下创作

IP 详情页支持单项下载和完整 IP 包下载：

- 文本按可编辑文本格式下载。
- 图片、音频和视频下载原始文件；网页预览仍使用现有限宽变体规则。
- 完整 IP 包为 ZIP，包含内容文件、封面、版本信息、目录和基础来源/署名说明。
- 学校可以把下载内容用于线下教学、练习和创作，不要求回传平台。
- 授权暂停、撤销或到期后，禁止新的在线查看、引用和下载；已经下载到本地的文件不做技术回收。
- 每次下载记录用户、学校、IP、版本、下载类型和时间。

## 3. IP 内容模型

一个 IP 是内容包，不是单个素材文件。第一期内容按四个大类组织：

```text
IP 内容
├─ 文本
│  ├─ 故事简介
│  ├─ 世界观
│  ├─ 人物小传
│  ├─ 剧本
│  ├─ 二创剧本
│  └─ 场景设定/创作说明
├─ 图片
│  ├─ 角色
│  ├─ 场景
│  ├─ 道具
│  ├─ 特效
│  └─ 风格参考
├─ 音乐与声音
│  ├─ 背景音乐
│  ├─ 主题音乐
│  ├─ 角色声音
│  ├─ 旁白
│  └─ 音效
└─ 视频参考
   ├─ 预告片
   ├─ 动作参考
   ├─ 表演参考
   ├─ 镜头参考
   └─ 成片片段
```

图片分类在用户端以“图片素材”大区下的子分类展示；文本、音乐与声音、视频参考分别集中展示，不拆成多个顶层菜单。

IP 项目复用现有素材和媒体存储。文本内容由 IP 内容项保存，图片、音频和视频内容项引用现有资产/媒体 ID，不复制文件。IP 内容项包含类型、分类、标题、摘要、排序和引用资源；发布版本保存经过白名单清洗的内容清单。

## 4. 页面与交互

### 4.1 IP 列表

`社区 → IP库` 使用现有用户端页面、Ant Design/Tailwind 和卡片模式。列表提供公共 IP、本校 IP 两个视图，以及关键词、内容类型和标签筛选。未登录用户不读取需要登录的下载和使用数据。

卡片展示封面、名称、简介、内容数量、公共/本校范围、版本和授权标签。多校授权不作为用户端文案。

### 4.2 IP 详情

详情页采用“资源全集”布局：

```text
IP 基本信息
├─ 封面、名称、版本、更新时间、简介
├─ 公共 IP / 本校 IP
└─ 操作：一键使用、下载资源包

文本内容
图片素材
├─ 角色
├─ 场景
├─ 道具
├─ 特效/风格参考
音乐与声音
视频参考
```

每个内容大区展示摘要卡、预览、数量和“查看全部”。音乐支持播放，视频支持播放预览，长文本支持只读预览。详情页只展示当前用户有权访问的版本和内容。

### 4.3 使用 IP

“一键使用”打开目标选择：Canvas、短剧或无限练习。用户选择已有项目或创建对应的新项目后进入工作区，再选择具体文本、图片、音乐/声音或视频参考内容。后端只建立 IP 版本和内容项的引用关系，不复制 IP 原始内容。

Canvas、短剧和无限练习保存 `ipId`、`ipVersionId`、内容项 ID 和当前学校上下文；新建项目和生成任务必须先通过用户归属、学校授权和版本状态校验。

### 4.4 下载 IP

详情页支持“下载当前内容”和“下载完整 IP 包”。下载前服务端重新校验公共范围或当前学校有效授权，生成短期签名 URL 或一次性 ZIP 下载，不把对象存储源地址长期放入页面。下载操作写入 IP 使用记录。

## 5. 后台设计

后台新增或扩展“内容运营 → IP 库管理”，包含三个 Tab：

```text
IP内容
学校授权
使用记录
```

### IP 内容

拥有 `content.manage` 的管理员可以创建草稿、录入内容、选择现有素材、上传 IP 封面、编辑草稿、发布新版本、停用 IP 和查看历史版本。发布前必须完成必填信息和至少一个有效内容项校验。

### 学校授权

拥有 `education.manage` 的管理员可以为已发布 IP 创建、暂停、撤销和到期授权。授权表单选择学校、授权模式、开始时间、结束时间和备注。独家授权冲突在 service 和数据库约束两层拒绝。

### 使用记录

管理员可以按 IP、版本、学校、用户、动作和时间分页查询引用与下载记录。记录不保存文件密钥、长期签名 URL 或文本私密草稿。

第一期不新增权限类型：完整平台管理员拥有 `content.manage` 和 `education.manage` 时可完成全部 IP 操作；只具备其中一项的管理员只能访问对应 Tab。

## 6. 数据与服务边界

建议新增以下领域对象：

```ts
type IpVisibility = "public" | "school";
type IpAuthorizationMode = "multi_school" | "exclusive";
type IpAssetKind = "text" | "image" | "audio" | "video";
type IpVersionStatus = "draft" | "published" | "disabled";

type IpLibraryItem = {
    id: string;
    ipId: string;
    versionId: string;
    kind: IpAssetKind;
    category: string;
    title: string;
    summary: string;
    assetId?: string;
    text?: string;
    sortOrder: number;
};
```

服务端分层保持现有约定：Route Handler 处理 Session、入参和响应；IP access service 判断公共范围、学校 context、授权状态和版本；repository 使用 `school_id`、状态、版本和分页定向查询；下载 service 复用现有媒体访问和签名 URL 能力。

## 7. 非目标

第一期不建设：

- 版权方/创作者线上投稿
- 线上版权审核流程
- IP 商城、订单、支付和学校结算
- 作品公开发布、首页推荐或商单使用规则
- 下载文件的远程回收
- Canvas、短剧和 IP 之间的项目转换
- 复杂的逐内容项授权编辑器
- 多学校之间的协作编辑

## 8. 验收条件

- 用户端入口为 `社区 → IP库`，列表只有“公共 IP”和“本校 IP”。
- 公共 IP 的登录用户可以查看、使用和下载；本校 IP 只对当前授权学校 active 成员可见。
- 独家授权在本校 IP 卡片上显示；多校授权不在用户端显示。
- IP 详情按文本、图片素材、音乐与声音、视频参考四个大区展示，图片具备角色、场景、道具等子分类。
- 平台管理员可以创建、编辑、发布 IP 和发布新版本；学校与普通用户不能提交或修改 IP。
- Canvas、短剧和无限练习可以引用 IP 内容，引用记录绑定具体 IP 版本。
- 用户可以下载单项内容和完整 IP 包；下载记录包含用户、学校、版本和时间。
- 授权暂停/撤销/到期后新的在线访问、引用和下载被拒绝，历史下载不被删除。
- 不同学校之间无法读取本校 IP、媒体源文件或下载链接。
