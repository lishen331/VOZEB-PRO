## 1. 目标与纠偏

本次不是把 L 的几个按钮“嵌入” V，也不是继续在现有大卡片上追加字段，而是：

> 以服务器生产版 LocalMiniDrama 的 `FilmCreate.vue` 为业务和交互基准，恢复 L 的制作工作台层级、分组、按钮顺序、镜头卡片结构和操作习惯；再把 V 已有的服务端任务、权限、团队审批、OSS、画布和统一模型能力接回对应位置。

验收标准不是“接口存在”或“字段存在”，而是用户从 L 切换到 V 后，主要操作路径、信息层级和按钮位置无需重新学习。

## 5. 段落/幕分组映射

### L 行为

L 的分镜不是简单平铺，而是依据分镜返回的：

- `segment_index`
- `segment_title`

在镜头序列之间渲染“第 N 幕 + 幕标题 + 镜头范围”的分组头。

### V 目标

保留 V camelCase：

- `segmentIndex`
- `segmentTitle`

目标行为：

- 仅在一幕的第一个镜头显示分组头；
- 显示镜头范围，例如“镜头 1–4”；
- 左侧镜头目录按幕折叠/展开；
- 点击幕标题可定位到该幕首镜头；
- 没有段落字段时按当前镜头顺序渲染，不猜测段落；
- 重新拆镜时服务端原子替换当前集结果，不能留下旧幕和新幕混排。

当前 V 已有字段映射基础，但前端真实工作台未达到 L 的分组呈现。

## 6. 镜头控制栏映射

每个镜头必须在卡片外拥有独立控制栏，顺序目标如下：

1. 镜头编号
2. 镜头标题
3. 运镜/镜头类型标签
4. `⚙ 分镜配置`
5. 经典分镜 / 全能模式切换
6. `＋ 新增`（在当前镜头前插入）
7. 删除

控制栏的操作不能藏在大卡片底部，也不能只用无文字图标让用户猜含义。

### 分镜配置弹窗至少包含

- 镜头时长
- 镜头景别/摄影字段
- 运镜方式
- 画面比例继承状态
- 首/关键/尾帧模式
- 对白/旁白状态
- 当前镜头资产引用摘要
- 保存/取消

保存必须服务端持久化，不能只改前端临时状态。

## 7. 镜头卡片三栏映射

### 左栏：剧本与资产引用

必须包含：

- 角色多选下拉框；
- 场景单选下拉框；
- 道具多选下拉框；
- 只显示项目内真实资产；
- 没有资产时显示可操作的空状态；
- 资产缩略图和名称；
- 点击缩略图预览；
- 资产引用变更后保留 ID 并自动保存；
- 不允许用名称猜测资产或创建幽灵资产。

### 中栏：视觉生成

必须包含：

- 图片提示词/画面描述；
- 首帧、关键帧、尾帧三个槽位；
- 专业帧提示词入口；
- 帧锁定、上传、候选接受；
- 分镜图预览；
- 重新生成分镜图；
- 生成状态和错误状态；
- 可选序列图布局；
- 生成结果和历史版本。

### 右栏：旁白、视频和任务

必须包含：

- 对白音频状态和生成按钮；
- 旁白音频状态和生成按钮；
- 按音频拆镜入口；
- 视频提示词/全能提示词编辑区；
- 生成分镜视频；
- 检查状态；
- 取消/重试/恢复入口；
- 视频预览；
- 当前任务执行阶段。

三栏可以使用响应式布局：桌面端三栏，窄屏端按“剧本资产 → 视觉 → 音频视频”顺序纵向排列，但不改变业务顺序。

## 8. L 与 V 资产引用规则

### L 的可见行为

- 镜头可以直接选择角色、场景、道具；
- 资产显示缩略图；
- 可以在镜头内添加或移除角色/物品；
- 资产和镜头关系清晰可见。

### V 的保留原则

- V 服务端真实 ID 绑定优先于 L 的名称显示；
- UI 可以显示 L 风格的下拉框和缩略图，但提交必须使用：
  - `sceneId`
  - `characterIds`
  - `propIds`
- 生成图/视频只读取当前镜头绑定资产的主参考图；
- 项目外资产不可被引用；
- 资产删除或失效时，镜头显示明确缺失状态，不能静默生成。

## 9. 提示词与生成链路映射

### L 的生产链路

```text
故事/剧本
→ 角色、场景、道具提取
→ 分镜 JSON（包含资产 ID/关联）
→ 分镜提示词
→ 首/关键/尾帧提示词
→ 图片任务
→ 视频任务
```

### V 目标链路

```text
可编辑 L 模板正文
+ 当前项目/剧集/镜头/风格/比例
+ 真实资产关系和主参考图
+ 不可编辑结构化输出契约
→ 服务端任务
→ 服务端保存
→ 前端按状态渲染
```

不能继续使用前端通用字符串直接拼接后调用图片/视频模型。

## 10. 任务状态映射

### L 使用习惯

- 执行中显示明确进度；
- 可以停止批量任务；
- 失败显示原因；
- 可以重试；
- 任务不会因为刷新消失；
- 已完成任务不继续出现在“执行中”。

### V 目标状态

| 状态 | 前端显示 | 是否继续轮询 | 是否允许重试 |
|---|---|---:|---:|
| queued/pending | 排队中/等待中 | 是 | 否 |
| running/polling | 生成中/处理中 | 是 | 否 |
| result_ready/persisting | 结果保存中 | 是 | 否 |
| success/completed | 已完成 | 否 | 可重新生成 |
| error | 失败 + 原因 | 否 | 是 |
| cancelled | 已取消 | 否 | 是 |
| needs_review | 待检查 | 否，等待用户检查 | 检查原任务，不重建 |

批量取消的语义必须是：

- 立即停止后续提交；
- 已提交上游任务继续由服务端同步；
- 批量摘要显示成功/失败/取消/待检查数量；
- 不把“前端 AbortController 已取消”等同于“上游任务已取消”。

## 11. 画布映射

画布不删除，也不改 V 原生 Canvas。

目标：

- 一集一个画布；
- 同一项目同一集复用画布 ID；
- 不同集隔离；
- 从镜头控制栏进入画布携带项目/集/镜头 ID；
- 画布顶部显示短剧项目和当前集；
- 画布可切换剧集；
- 返回时回到分镜工作台，并定位到原镜头；
- 任务执行中切换画布不能清空或重复提交任务；
- 普通 `/canvas` 和其他 Canvas 项目不受影响。

当前 V 这部分已有基础实现和实测闭环，但必须在工作台重排后再次回归。

## 12. V 独有能力保留清单

以下能力不是 L 的要求，但必须保留：

- 团队协作与审批；
- 项目邀请链接/二维码；
- 组长、副管理员和成员权限；
- 站内待办/审批状态；
- 服务端任务持久化、恢复和未知状态检查；
- OSS/对象存储；
- V 原生 Canvas 全部能力；
- 统一模型目录和能力路由；
- 多管理员配置隔离/全局配置约束；
- 项目导入导出（已实现部分继续保留）；
- V 现有的图片、视频、音频、算力和账户能力。

这些能力应作为 L 风格工作台中的侧栏、弹窗或状态入口接入，不能挤压或打乱 L 主制作路径。
