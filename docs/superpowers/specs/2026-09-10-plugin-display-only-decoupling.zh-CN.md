# 插件市场开关解耦实施记录

日期：2026-09-10

## 最终需求

插件市场开关只负责前台显示：导航、首页入口、功能卡片和创建入口。关闭插件不再阻断已进入页面的业务、不再阻断 API、任务创建/查询/恢复/取消/重试、项目读取或共享媒体能力。

“短剧实验室”前台统一显示为“创意工坊”；内部 `drama-lab` 标识、数据库和 API 路径保持不变。

## 修复策略

集中修改服务端模块开关守卫 `requireFeatureModuleEnabled`：该守卫改为兼容空操作，仅保留调用点兼容，不再读取展示开关并拒绝请求。前台 `FeatureModuleGate`、导航过滤和入口隐藏逻辑继续保留。

业务安全边界继续由登录、项目/成员权限、参数、模型渠道、任务幂等和计费规则负责。

## 验收

- 任一插件关闭：对应入口隐藏；直达页面及已进入页面的业务 API 不因展示开关被拒绝。
- 短剧与创意工坊彼此独立。
- 共享 image/video/audio/text API 不被插件展示开关熔断。
- 关闭插件不删除数据、不取消任务、不影响历史恢复。
