# 平台课程附件弹窗与本地上传设计

## 目标

将管理员课程创建/编辑从侧边 Drawer 改为响应式 Modal，并把平台附件从 URL 文本改为多选本地文件上传。上传链路必须覆盖案例包实际包含的 `.docx/.pptx/.xlsx/.png/.jpg/.jpeg/.webp/.mp4/.mov`，并接受 `.zip`；ZIP 作为单个文件保存，不自动解包。

## 设计

- 课程编辑器使用 Ant Design `Modal`，桌面端限制最大宽度，窄屏不超过视口并让内容区滚动。
- 附件字段保存稳定的本地/对象存储地址、原文件名、MIME、字节数和展示标题；编辑已有课程时展示已保存附件，支持移除。
- 浏览器为每个待保存 `File` 发起一次以文件为请求体的流式上传请求，不把大文件转换为 Data URL，也不依赖 multipart 解析。
- 服务端上传接口校验管理员课程权限、文件名和非空请求体，使用请求流写入临时文件，再复用项目对象存储配置；未启用对象存储时落到 `reference-assets/permanent`。
- 课程保存仅在所有附件上传成功后提交；上传或课程保存失败时删除本次新上传且尚未被课程引用的文件。关闭弹窗不会上传文件。已有附件只按稳定 ID/URL 保留，不重复上传。
- 附件下载继续经过鉴权的 reference asset 路由，支持 `Range` 和原文件下载头；不为附件增加公开 URL。
- 本地媒体登记的类型扩展为 `attachment`，以便后台本地媒体页继续按类型统计和删除引用保护。

## 数据流

```text
选择 File[] -> Modal 内存表单
    -> 保存：逐文件 PUT /api/admin/course-attachments
    -> 临时文件 -> object storage 或 reference-assets/permanent
    -> 返回稳定附件元数据
    -> POST/PATCH /api/admin/courses
```

## 错误处理

- 空文件、缺失文件名、不在允许扩展名内或写入失败返回中文错误，课程不落盘；Office 文件即使浏览器未提供 MIME，也按允许扩展名映射到标准 MIME。
- 任一附件上传失败时清理本次已完成上传，保留表单内容供管理员重试。
- 课程 API 只接受服务端生成的附件地址/键，不接受外部 URL。
- 取消弹窗不触发上传；上传或课程提交失败时按本次返回的稳定存储键回收未被引用的附件。

## 验收

- 创建和编辑均显示 Modal 而非 Drawer。
- 可多选本地文件，文件名、类型、大小和删除操作可见；不再出现 URL 校验。
- `.docx/.pptx/.xlsx`、图片、`.mp4/.mov` 和 `.zip` 均通过扩展名/MIME 契约测试；浏览器至少用图片和 ZIP 夹具验证多文件选择、上传与课程保存。
- 浏览器回归覆盖桌面、390px、430px，无横向溢出；上传失败可重试，成功刷新后附件仍可下载。
