# 多角度练习：返回入口与结果叠卡对齐

## 需求与范围

- 页面标题旁增加「返回无限练习」入口，固定打开 `/practice`，不依赖浏览历史。桌面和手机都可见、可用键盘聚焦。
- 中栏结果叠卡的前卡、底卡共享宽高。前卡填满结果卡框，底卡用轻微位移保留叠卡层次；切换结果、图片比例不同时外框不变。
- 结果图按原比例居中完整显示，不拉伸、不裁切；左右翻页按钮位于前卡内。保留现有提示词、下载、历史恢复和生成流程，无接口、幂等、计费或数据库变更。

## 修改与验收

1. `web/e2e/infinite-practice-multi-angle.spec.ts`：补充实际点击返回，以及桌面与 390/430px 对前、后卡尺寸、图片居中、非方图切换、箭头位置的回归。舞台定位使用稳定标识，避免依赖构建器生成的 CSS 类名。
2. `multi-angle-workbench.tsx`：沿用 Next `Link` 和现有主题按钮样式。`multi-angle.module.css`：显式固定前卡宽度并保留现有桌面高度约束，预留叠卡偏移空间，图片使用 `contain` 居中。
3. 运行多角度浏览器回归、类型/格式/文档校验；从最新 `origin/develop` 正向发布，只由 Staging image 部署共享测试服。核对运行版本、就绪与 Worker 心跳，不发布生产，不调用收费上游。
