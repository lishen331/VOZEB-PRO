# 无限练习：结构化反推提示词与同页文生图

**验收目标：** 学生在 `/practice/reverse-prompt` 里完成「看原图 → 理解画面如何写成提示词 → 编辑提示词 → 生一张图 → 对照」。反推是基于可见特征的建议，不是找回原始提示词，不承诺复刻。

## 交互与数据契约

- 左栏沿用原图、来源、分析重点与额外要求。中栏展示五部分（主体与造型、构图与视角、色彩与光影、风格与质感、关键约束），每部分分「图里看到了什么」与「提示词可以怎么写」；完整生图提示词可复制。诊断信息独立折叠。
- 宽屏三栏，窄屏依次展示。右栏独立可编辑，分析成功只填词，不自动生图。原图始终只进分析任务。点击「生成一张」后用练习生图池的虚拟模型 `gamaimage` 生成结果，原图、分析和试生成均保留在同页。提示词编辑不回写分析；新分析成功后以其完整版重新填右栏。两次计费沿用现有规则，试生成不暗中调用生产池。
- 模型返回 JSON：`{sections:{subject,composition,lighting,style,constraints}, fullPrompt}`，每个分项有 `observation`、`phrase`。分析重点与额外要求只影响分析内容，不替换格式和约束。前端可读旧纯文本及部分有效 JSON；完整 JSON 无可用提示词时不给右侧注入原始结构数据。
- 沿用 `POST /api/practice/image-tools`，新增仅 `toolId=reverse-prompt` 可用的 `action=try-generate`，请求只含工具、动作、提示词和请求 ID。服务端鉴权、验证练习资格，选择练习图片池入口 `gamaimage`，不走独立练习工作流，调 `/api/image-tasks`，`kind=generation`、`references=[]`、沿用单张图片任务（不使用批量或分层），沿用可信练习上下文和既有计费。拒绝参考图、蒙版、外部模型/路由/配置覆盖；池不可用直接报错。
- 试生成有自己的状态和错误，失败保留草稿；提交成功后的查询中断只查询原任务，不自动再次扣费。请求未知时可用同一请求 ID 继续，服务端沿用幂等机制。生成图不自动写入个人素材库。

## 变更与验证

1. `web/src/lib/practice-reverse-prompt.ts`：结构定义、指令构建、安全解析；先验证标准、围栏 JSON、旧纯文本和无效结果。
2. `web/src/app/api/practice/image-tools/route.ts`：分离分析与纯文本练习生成，两处分开选模型；扩充 route 测试覆盖无图请求、拒绝注入、练习权限及无可用池。
3. `web/src/app/(user)/practice/components/`：保留既有图像工具工作台，实现分析分块和试生成组件，复用现有轮询与图片读取。验证三栏/移动端顺序、不会自动提交、试生成失败或恢复后草稿与中间结果不串状态。
4. 本地依次运行专项 Vitest、类型检查、改动文件 ESLint/Prettier，并用模拟接口的真实浏览器验证不会上传原图到试生成请求。未授权推送或部署，未调用收费模型。
