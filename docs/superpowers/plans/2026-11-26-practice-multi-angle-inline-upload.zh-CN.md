# 多角度练习：工作台内上传主体图

## 目标与边界
用户进入多角度练习即看到现有操作台、生成结果和历史记录。取消跨列上传页，只在左侧原主体画面内显示上传空态。保留选择图片、拖入、粘贴和「用示例图试试」，不自动上传示例或提交生成。

## 实施
- `multi-angle-workbench.tsx` / `multi-angle-stage.tsx`：始终渲染三栏，只有主体舞台内切换上传区与主体、环绕控件、实时取景。无已就绪主体时禁止生成；重新选择时清空当前主体和结果，历史保留。恢复历史继续使用现有主体图和快照，不新增生成请求。
- `multi-angle.module.css`：删除跨列上传卡样式；紧凑上传空态沿用主体舞台的尺寸，兼容桌面、390px、430px。保留现有布局、结果卡、提示词及历史弹层。
- `infinite-practice-multi-angle.spec.ts`：覆盖初次打开、示例、自选文件、重新选择、拖放粘贴和未上传时恢复历史。使用本地 fixture，不调用收费模型。

不修改接口、计费、存储、数据库或其他练习。本阶段只修改与本地验证，不推送、不部署。

## 验证记录
- 旧版在桌面未选图时找不到操作台内的上传入口，新增回归如预期失败。
- 新版通过桌面及 390px、430px 的本地 Playwright 回归（含初始化共 6 项）：进页显示工作台、示例/选图/拖放/粘贴、舞台高度稳定、重新选择及历史恢复。未调用真实模型。
- 本地生产构建、类型检查、变更范围 ESLint / Prettier、16 项专项单测和开发地图 / 接口索引校验通过。未进行本地 Docker 人工验收或远端发布。
