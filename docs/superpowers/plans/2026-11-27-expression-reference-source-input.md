# 表情参考：原图输入体验

**目标**：仅补齐点击或拖入上传、粘贴截图和一键示例图。保留个人素材库、原图预览、表情设置、生成结果、结构化提示词及历史。

## 实现

- 仅在表情参考启用拖放区及页面图片粘贴。点击上传仍用原生文件选择器；拖放接收单张图片，输入框、可编辑区域和非图片剪贴板不拦截。已有预览可拖入或粘贴替换。
- 三个新入口统一走原有受管素材上传及替换流程；示例图片取自站内内置素材，载入不生成、不扣费。失败保留原图，忙碌、恢复或表情弹窗打开时不接管拖放与粘贴。正常换图沿用现有表情设置重置逻辑，不清除历史。
- 不改接口、数据库、模型池或其他工作台；不改生产。

## 验收与发布

- Playwright 使用独立学校/账号验证点击、拖放、粘贴、示例图、预览可见、个人素材库还在，且全程没有发送生成请求；保留原有表情历史/教学回归。
- 运行变更文件格式与 lint、类型检查、生产构建、相关单测，更新并验证开发地图。人工验收后走独立分支 PR → `develop` → Staging image，核对版本和就绪状态。
