# 短剧实验室分镜卡 L 等价迁移开发文档

日期：2026-09-13  
范围：仅 VOZEB-PRO 短剧实验室分镜工作台的分镜卡及其直接提示词、图片、视频、音频链路。

## 1. 决策与边界

1. LocalMiniDrama（L）迁移来的分镜能力，业务语义、字段优先级、参考图槽位和最终上游请求严格照抄 L；V 只用自身 React/Ant Design/Tailwind、权限、任务、计费、OSS、PostgreSQL 和模型路由承载。
2. V 自有且不冲突的能力保留：画布定位、任务状态/取消/恢复、上传、历史候选、主图、审批、批量任务。
3. 不修改普通 Canvas、Agent、普通短剧、资产编辑闭环、成片导出或公共模型协议。
4. 最终验收不是“界面像 L”，而是图片和视频上游请求的最终 prompt、参考图数组、顺序、模式和参数与 L 等价。

## 2. L 源码基线

- 分镜提示词统一弹窗：`LocalMiniDrama/frontweb/src/views/FilmCreate.vue:2268-2350`
- 全能卡片片段描述与下拉：`FilmCreate.vue:1188-1245`
- 全能生成/润色菜单：`FilmCreate.vue:5922-6000`
- 全能请求包与无图强制语义：`LocalMiniDrama/backend-node/src/services/universalSegmentPromptBundle.js`
- 分镜配置/视频参数弹窗、首尾帧专用提示词、最终视频提交均以 L 当前源码为准。

## 3. 分镜卡展示

### 标题栏

- 显示分镜序号、标题、时长/景别/运镜、分镜图状态、视频状态。
- 保留画布定位、原有任务入口、铅笔、分镜配置、模式切换、新增、收起。
- 删除固定删除按钮；悬浮卡片标题栏右上角显示 `×`，点击后二次确认。
- 移除重复“任务状态同步”按钮。

### 模式维度

- 卡片内仅一个创作模式切换：`经典分镜 ↔ 全能模式`。
- 首尾帧是经典模式的外部开关：关闭显示单张经典分镜图；开启显示首帧和尾帧。
- 标题旁不是模式标签，仅显示生成状态。

### 三栏

- 左栏：真实资产 ID 绑定及主参考图缩略图，不显示提示词摘要。
- 中栏：经典单图 / 首尾帧 / 全能片段描述。
- 右栏：分镜视频、对白/旁白音频、视频生成操作，不显示视频提示词摘要。

## 4. 操作栏

- 经典图片区左：生成/重新生成分镜图、上传分镜图；右：查看/编辑提示词、配音。
- 首尾帧区：首帧和尾帧分别生成、上传、候选、设置主图、锁定等 L/V 已有操作；右侧保留查看/编辑提示词、配音。
- 全能区：片段描述文本框、全能提示词菜单、查看/编辑提示词、配音。
- 视频区左：生成分镜视频、上传分镜视频，两个按钮紧靠；右：按音频拆镜。

## 5. 模式化提示词弹窗

### 经典单图

图片提示词：原始提示词 `imagePrompt`；通用优化 `polishedPrompt`（可生成/重新生成）。  
视频提示词：`videoPrompt`。

### 首尾帧

图片提示词：原始提示词；首帧最终提示词（独立重新生成）；尾帧最终提示词（独立重新生成）。不显示通用优化。  
视频提示词：`videoPrompt`。

### 全能模式

图片提示词：只显示原始提示词。  
视频提示词：普通 `videoPrompt`；全能参考提示词 `universalSegmentText`（生成/润色）。不显示通用优化、首帧或尾帧提示词。

保存只写对应字段；重新生成一个派生字段不得覆盖其他字段或原始提示词。

## 6. 分镜配置（铅笔）

严格对齐 L 的“视频参数/分镜配置”业务：创作模式、标题、地点、时间、时长、景别、运镜、氛围、镜头视角、灯光、景深、空间布局锚点、动作、对白、解说旁白、画面结果、视频提示词。保存后按 L 更新结构字段和允许更新的派生值，不覆盖用户锁定/手工保存的专用提示词。

## 7. 经典图片最终请求

- 服务端组合：L 提示词正文 + 项目风格/比例 + 当前结构字段 + 真实资产 + 不可编辑输出/一致性合同。
- 最终 prompt 使用 `polishedPrompt`；无值时按 L 的通用优化逻辑生成并持久化。
- 合同包含主体与动作、场景与空间、景别、机位/镜头角度、构图、光线与色调、角色白名单、资产一致性、风格、比例、禁止项。
- `sceneId/characterIds/propIds` 仅用于查找真实资产和主参考图，禁止把内部 ID 写成自然语言交给模型。
- 参考图只取当前镜头已绑定资产的真实主参考图。

## 8. 首尾帧最终请求

- 首帧、尾帧分别读取各自专用 prompt；不读取 `polishedPrompt`。
- 复用 L 的空间布局锚点、角色白名单、初末状态连续性、前镜尾帧衔接和非本镜人物清洗。
- 图片请求参考图和顺序严格对齐 L；首/尾帧视频请求读取首帧、尾帧及 `videoPrompt`。

## 9. 全能最终请求

- `universalSegmentText` 非空时，视频主 prompt 只发送该字段，不拼接 `videoPrompt`；为空才退回普通视频提示词。
- 参考图只取绑定资产主图，固定顺序：场景 → 角色（分镜绑定顺序）→ 道具（绑定顺序）；不包含经典中间主图。
- 服务端生成 `@图片1..N` 映射，提示词编号和真正发送给视频接口的图片数组顺序完全一致。
- 有四宫格/多视角资产时，提示词明确仅参考空间/身份/材质，成片为单镜头完整画幅，禁止分屏宫格。
- 生成全能提示词：要求至少一张真实参考图；润色：要求已有全能正文并检查参考图。
- 无参考图生成/润色：仅跳过至少一张图的前置校验；不伪造已存在槽位。允许无 `@图片N`，或仅生成待后续核对的占位。
- 保留 L 的多子分镜格式、时长合计校验、镜序/邻镜上下文和生成后清洗。

## 10. 配音

- 图片/片段操作栏右侧“配音”打开弹窗。
- 对白和旁白独立显示文本、状态、生成按钮；无文本时禁用并解释。
- 复用 V 音频任务、状态、取消、恢复；生成内容和字段优先级照抄 L。
- 按音频拆镜保留在视频操作栏右侧，不放进配音弹窗。

## 11. 测试与发布门禁

1. 字段规范化/JSON roundtrip：所有模式字段不丢失。
2. UI 行为：模式切换、弹窗字段、按钮布局、悬浮删除、子按钮阻止卡片点击。
3. 经典请求：最终 prompt 与参考图角色/顺序测试，内部 ID 不进入 prompt。
4. 首尾帧请求：专用 prompt、连续性、参考图和通用优化隔离测试。
5. 全能请求：全能优先、普通视频兜底、`@图片N`、图片顺序、无图强制和时长格式测试。
6. 配音/按音频拆镜专项测试。
7. Vitest 专项和全量、TypeScript、ESLint、Prettier、production build。
8. Chromium 在 1280×900、1920×1080、390×844 检查无横向溢出和按钮可命中。
9. 使用已授权测试额度真实执行：经典生图、首尾帧图、全能视频（至少覆盖请求提交及上游记录）；核对最终请求日志，不以加载状态代替成功。
10. 推送 `develop`，GitHub Actions 全部成功，SSH 确认测试服务器 App/Worker 使用新 SHA 且 HTTP 200 后才汇报。
