# 局部编辑：独立历史记录栏

## 目标与范围

学生应能一边编辑、一边对照结果和真实提示词，同时直接回看自己的历史，不必滚过输入表单。仅调整 `/practice/local-edit`，不改反推提示词等其他练习、不改历史接口、授权、7 天保留、生成、计费或数据库。

## 布局与交互

- 宽屏：输入与设置／生成结果与诊断／历史记录三栏并排，中间最宽，右栏窄于输入栏；沿用平台卡片、间距和主题色。历史不再出现在输入卡片内。 右栏与左侧卡片上下沿对齐，即使历史为空也保持等高；不改变栏宽。
- 中等宽度保留输入、结果两栏；历史独立成卡，位于两栏下方。手机按输入、结果、历史自然纵排，不出现横向滚动。
- 历史列表保留最近 5 条成功练习（最新优先）、缩略图、时间、说明、选中态以及加载、空态和失败重试。空态也在独立历史卡中。
- 点历史只切换中间的成品与对应提示词；只有「用这次设置继续」才恢复当时的原图、蒙版、说明。不会自动生成、扣费或保存素材。

2. 在 `practice-image-tool-workbench.tsx` 仅对局部编辑启用第三列，将现有 `LocalEditHistory` 放到结果之后。由 `practice-local-edit-learning.tsx` 使用带标题的独立卡片；不拆分或复制历史状态。
3. 运行桌面、390px、430px 浏览器用例（本地媒体夹具），覆盖草稿保留、选区恢复且不产生生成/保存请求；执行质量检查和开发文档校验。
4. 仅通过 PR 合入 `develop` 发测试环境；核对部署工作流、实际 App 与 Worker 版本和就绪接口。不发布生产。
