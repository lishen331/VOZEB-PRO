# 多角度练习：首屏工作台与右侧历史

## 用户目标
在桌面同时看到操作台、生成结果和历史。学生不必下滑页面才能生成或恢复历史。

## 实施
1. `multi-angle-workbench.tsx` 与 `multi-angle.module.css`：工作区采用等宽等高的操作台与结果区，加右侧窄历史栏。桌面首屏锁定工作区高度，图片舞台压缩但保留拖拽和右上实时取景。未选图时，上传区横跨前两列，历史栏仍可用。
2. `angle-params-panel.tsx`：压缩画面与常用参数空间，保留所有控件；较矮的桌面窗口只滚动参数内容，重置和生成始终可见。结果区内部滚动，不因空状态或长提示词改变面板外框。历史列表单独滚动。
3. `multi-angle-results.tsx`：历史卡控制和数据不变；窄屏通过顶部常驻按钮打开历史弹层，点击历史后关闭弹层并恢复原有快照。桌面继续使用右栏。图内箭头、结构化提示词、历史恢复以及现有生成逻辑不变，无 API、计费、表结构修改。
4. 更新开发地图与浏览器用例：测试桌面 1280×720、1440×900 等宽等高、主要按钮首屏、历史独立滚动和上传空态；390px、430px 验证无横向溢出及随时打开历史。从历史恢复不增加任何生成请求。仅通过 develop PR 发布测试，不发布生产。

## 本地验证
- 旧版在 1280×720 下无法通过等大、首屏和历史位于结果右侧的验收断言。
- 新版本生产构建、类型检查、改动范围的 ESLint / Prettier、专项 Vitest（16 项）与 Playwright（含安装准备共 6 项）通过。浏览器覆盖 1280×720、1440×900、390px、430px 及历史列表独立滚动，使用本地模拟生成记录，不调用真实模型。
- 开发地图和接口索引校验通过：447 个 API Route 文件、78 个页面入口、147 张 PostgreSQL 表。
