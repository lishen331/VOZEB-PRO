# 创作工坊独立前端显示配置

## 范围

本次将插件市场的“创作工坊”卡片从子功能弹窗改为独立页面 `/admin/drama-lab-features`。页面按剧本与项目、资产准备、分镜生成、分镜工作台、审核与成片分组，并覆盖模块、入口、按钮和选择框级别的显示开关。

## 配置契约

细粒度键复用现有 `app_settings.feature_modules` JSON，不新增表和迁移；键名统一以 `drama-lab-ui-` 开头。旧环境缺失键时默认开启。此配置只控制创作工坊前端是否显示，不改变 API 权限、生成流程或历史数据。

## 交互

- 插件市场点击创作工坊卡片进入独立页；点击卡片右上角总开关不触发跳转。
- 独立页读取 `/api/admin/settings`，保存通过现有 `/api/admin/settings` PATCH。
- 支持恢复默认；保存后刷新仍保留。
- 页面不加入后台侧边栏固定菜单。

## 验收

1. `/admin?section=plugins` 点击创作工坊卡片进入 `/admin/drama-lab-features`，不再弹窗。
2. 页面展示分层开关，默认全部开启。
3. 关闭/开启任一键后保存，重新打开页面可读到相同状态。
4. 未配置细粒度键的旧数据按开启处理。
5. 不改变普通短剧、Canvas、Agent、服务端 API 和业务数据。

## 入口修正

正式后台不增加左侧导航项；仅保留插件市场创作工坊卡片跳转到独立配置页。
