# 无限练习「局部编辑」：最近练习与提示词拆解

## 已确认需求与边界
- 左侧生成按钮下显示当前登录用户最近 5 条有成品的局部编辑练习，显示缩略图、修改说明和时间。刷新后从现有任务库读取，沿用 7 天任务保留策略；不自动写个人素材库、不复制媒体，也不把生成失败伪装成成品。
- 点历史只改变右侧预览；原图、可按需查看的笔刷选区、结果和原始说明必须同属一个任务。仅点击「用这次设置继续」才恢复左侧原图、蒙版和提示词，不触发生成或扣费。历史素材失效时提示重新上传，不覆盖草稿。
- 结果下方展示原始说明与教学拆解（改什么 / 改成什么 / 什么不变），给可复制、可显式填回的参考写法。教学写法是模板建议，不是假称学生写过的内容，不对用户提示词做静默改写，不调用额外模型。
- 不修改生成、蒙版编码语义、模型池、计费、保存到素材库或其它图像工具。保留诊断折叠。仅本地开发与隔离回归；不推送、不部署、不产生真实生成费用。

## 实施
1. 复用 `GET /api/practice/image-tools` 读取历史，登录并验证练习权限；查询图像任务时在限定条数前按用户、已成功、未过期、练习档案及局部编辑标识筛选。兼容既有「局部编辑」标题与管理素材快照；仅返回可显示的白名单字段及同源路径，不返回原始任务、凭据、签名参数或内部系统提示词。
2. 扩展练习工作台：以独立的查看快照绑定结果、原图、选区和原始说明；恢复时把已有蒙版的透明区域重新着色到编辑画布，禁止把该预览或画笔图层混入生成结果。无历史、获取失败和恢复错误有独立状态，不打断生成。
3. 补测试：权限、历史字段与资源脱敏、不同工具过滤、结果与提示词不串、只查看不改草稿、显式恢复选区、填回不提交、刷新/回访和响应式；更新开发地图与接口索引。

## 本地验证

- 全量 Vitest（JSON 模式）：6,530 通过、41 跳过。历史隔离覆盖当前用户、当前学校、工具、状态和过期时间；PostgreSQL 查询通过 SQL 形状测试，未连接真实数据库。
- Playwright：桌面 Chromium、390 px、430 px 共 3 个场景通过（另有 3 个安装准备测试通过）。使用本地媒体和任务回应夹具验证切换历史不覆盖草稿、填回、恢复选区像素、重载回看及无意外生成/入库请求。未调用真实上游。
- 变更文件 ESLint / Prettier、Webpack 生产构建、接口索引与开发地图校验通过（447 个 API 路由文件、78 个页面、147 张表）。Windows 工作树的 standalone 启动遇到 Sharp 同路径复制问题，浏览器测试以同一构建产物通过本地 Next 入口运行。构建前类型检查通过；构建后重跑类型检查时，Webpack 额外生成的严格检查报告三个既有后台页面/路由的导出问题；隔离该生成目录后通过，未改后台源码。
