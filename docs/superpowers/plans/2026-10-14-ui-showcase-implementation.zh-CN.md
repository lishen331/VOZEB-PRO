# 独立 UI Showcase 实施清单

日期：2026-10-14。依据已确认的第一阶段视觉需求续做。仅新增隔离样板，不替换业务页面，不改接口、数据库、生成链路，不推送或部署。

## 实施顺序

1. 核对现有 `.vz-ds` 实现、仓库改动及已有 RED 测试；不覆盖其他任务的文件。
2. 先增加工作台专项回归：忙态防重复、模拟完成与重试、取消、真实本地文件预览和 URL 回收、可用响应式示意。
3. 最小补齐本地交互，移除 iframe，不为样板放宽全站安全头。
4. 并行补齐控件键盘交互、媒体放大/下载/音频播放；全部使用本地 Mock，明确不扣积分。
5. 补齐作用域 Token、明暗主题、焦点和 reduced-motion；验证长页面可滚动及门户隔离。
6. 跑专项 Vitest、TypeScript、ESLint、Prettier 和文档检查，保留失败的真实证据。
7. 使用独立 Next dev（不启动业务 Worker），真实 Chromium 验收 1440、1280、430、390 及平板，保存截图。
8. 交付组件、Token、路由、适配和逐步迁移说明；未经视觉验收不迁移正式页面。

## 验收约束

- 普通、悬停、按下、聚焦、禁用、加载、成功、警告、错误、选中状态可辨。
- 上传只创建浏览器本地预览，生成仅模拟，不发起真实生成或业务写请求。
- 不出现页面横向滚动、控件裁切、仅鼠标可操作的关键功能。
- 新样式与 AntD 浮层始终限制在 `.vz-ds` 内，旧主题与业务组件不变。

## 执行结果

实施 1–8 已完成。本次专项 76/76；真实 Chromium 11/11（五档屏幕、深浅主题及实际交互）；全仓 Vitest 5716 项通过、38 跳过；TypeScript、全仓 ESLint、本次格式与 UTF-8 通过。全仓格式保留 13 个无关既有文件的问题，不覆盖它们。开发文档已同步当前工作区 426 个 Route、61 个页面、144 张表，验证通过。

实际修复包含：模型快速键盘开合竞态、透明 radio 触控命中、内滚动根的 Popover 坐标系、Prompt 浮层手机端横向偏出、运行 shimmer 拦截重试、单次失败与再次生成时序、CommonJS 下载导入和 AntD 6 实际容器选择器。未使用强制点击、遮挡修复或安全头降级。
