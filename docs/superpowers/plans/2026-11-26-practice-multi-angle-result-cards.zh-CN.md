# 多角度练习：结果卡与提示词教学

## 验收范围

- 上传后桌面为「操作台｜生成结果」两栏，窄屏纵向排列。将小取景器嵌回操作画面右上角，沿用实时机位渲染，移除独立预览台。上传前后历史区始终保留。
- 生成多张时，结果上方显示一张图与叠卡效果，左右箭头位于卡片内部并循环翻页，保留机位标签；切换不发请求。单张不显示箭头或叠卡；不提供随机抽取。保留下载、排队、失败和无提交状态。
- 当前卡片下方展示机位、俯仰、景别、镜头与补充描述，可展开、复制完整提示词。景别未传入提示词时明确标明。结果跟随生成快照，不随操作台的即时机位变化；恢复历史使用该机位会话原已保存的提示词，不从生成图反推。没有提交记录的机位不冒充实际提交。

## 修改与验证

1. 扩展 `lib/angle-history.ts` 的单张结果模型，复用现有 `buildAnglePrompt` 及会话 `input.prompt`，不修改请求语义、API、数据库或其他练习页面。
2. 修改工作台与结果组件及局部样式。新批次和恢复历史时重置当前卡；切换期间保持箭头可操作、动画遵循减少动态效果设置。
3. 单测覆盖同批不同机位、原始历史提示词、缺失机位与关闭景别；Playwright 在桌面和手机验证取景器位置、翻页联动、历史恢复和不发额外生成请求。使用本地 fixture，不调用真实渠道。
4. 本次只本地开发，不推送、不部署。
