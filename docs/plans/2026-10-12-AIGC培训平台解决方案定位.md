# VOZEB PRO：中国高校/职校 AIGC 培训平台解决方案定位

## 1. 我们的产品不是一个单点 AI 工具

VOZEB 要卖给高校、职业院校和动漫/数字媒体相关专业的，是一套可以实施的 AIGC 培训与产教融合方案：

```text
课程内容与课件
    ↓
教师培训 / 师陪服务
    ↓
学生 AIGC 实训（无限练习、画布、故事板、图片、视频、音频）
    ↓
教师作业、过程评价与修改
    ↓
企业真实题目 / 商单实训
    ↓
作品集、项目交付与就业展示
```

平台是承载层，课程和师陪是交付层，企业项目和作品是价值证明层。三者必须一起设计和报价。

## 2. 面向谁卖

| 角色 | 购买/决策关心点 | 需要展示的证据 |
| --- | --- | --- |
| 院校领导/继续教育负责人 | 人才培养、专业建设、产教融合、可复制交付、学校品牌 | 课程包、实施周期、学生作品、企业合作案例、数据安全 |
| 二级学院/专业负责人 | 专业方向、课件、师资、实训室、课程考核 | 专业工作流、教师培训大纲、课时任务、评价标准 |
| 一线教师 | 好不好上手、备课时间、学生是否能完成、批改是否可控 | 教师工作台、课件、作业、反馈、失败重试和师陪支持 |
| 学生 | 能不能学会、能不能产出、能不能做作品集 | 任务式练习、角色/场景/分镜、视频结果、作品发布 |
| 企业/动漫集团 | 学生能力、项目交付、协作、版本和验收 | 企业题目、候选成果、反馈、版本、最终交付 |
| 学校信息化/采购 | 部署、账号、数据、权限、成本和售后 | 租户隔离、管理员、数据导入导出、服务 SLA/边界 |

## 3. 解决方案产品包

### 基础包：AIGC 教学入门

- AIGC 基础课程与教师培训。
- 统一创作入口、提示词/素材基础使用。
- 简单图片、短视频、音频练习。
- 教师作业、学生提交和反馈。

### 专业包：动漫/数字媒体实训

- 角色、场景、道具、分镜、镜头视频、配音和成片。
- 无限画布与故事板工作流。
- 专业课程包、课时任务、作品评价。
- 学生作品集与作品广场展示。

### 产教融合包：企业项目实训

- 企业真实/脱敏题目与参考素材。
- 班级或项目组分工、里程碑和版本。
- 企业反馈、返修、候选成果和正式交付。
- 教师指导、企业验收、作品归档和复盘。

### 服务包：师陪与课程共建

- 校前专业调研和课程设计。
- 教师集中培训、备课辅导和课堂陪跑。
- 模型/工作流配置、账号和素材治理。
- 试点复盘、课程迭代和年度内容更新。

## 4. 对标中国平台后的差异化

| 对标对象 | 它的强项 | VOZEB 不去正面竞争的地方 | VOZEB 应突出 |
| --- | --- | --- | --- |
| 国家智慧教育/智慧职教 | 公共资源、政策可信度、规模 | 不比资源总量 | 聚焦 AIGC 专业实训和项目作品 |
| 雨课堂/超星 | 课堂教学、互动、资源和学校覆盖 | 不比通用课堂工具 | 把 AIGC 生产嵌入课时、作业和评价 |
| 学堂在线/学堂 AI | 高校课程、AI 学习、院校合作 | 不比课程数量和名校品牌 | 课程共建、师陪、工作流实训、企业交付 |
| 即梦/可灵/度加 | 单点生成体验和模型能力 | 不比个人创作流量 | 学校管理、课程化、过程评价和交付 |
| 腾讯教育等方案商 | 校级解决方案、项目交付和生态 | 不比整体数字基座 | AIGC 专业培训的深度与交付速度 |

## 5. 10 月 22 日应该展示的销售闭环

不要从“我们有多少模型”开始。建议按客户购买逻辑展示：

1. 一门动漫/AIGC 专业样例课程：目标、课件、课时和评价标准。
2. 教师从课时发布一个“角色设定/分镜制作”任务。
3. 学生进入无限练习，使用参考素材完成角色、场景或分镜。
4. 结果进入画布/故事板，生成图片或视频并保留过程。
5. 学生提交，教师反馈，学生修改。
6. 企业题目进入商单实训，提交候选作品并完成验收。
7. 最后展示作品集、课程成果和学校/企业可以购买的服务包。

## 6. 当前最应该补的产品能力

| 能力 | 原因 | 方案优先级 |
| --- | --- | --- |
| 样例课程包 | 没有课程内容，平台无法销售培训方案 | P0 |
| 教师培训/师陪流程 | 客户买的是落地结果，不只是账号 | P0 |
| 课时任务 → 无限练习 → 提交 → 反馈 | 把 AIGC 工具变成教学产品 | P0 |
| 专业工作流模板 | 让教师和学生能快速开始 | P0 |
| 真实作品与企业题目 | 证明产教融合价值 | P0 |
| 学校实施/管理员/数据边界 | 解决采购与交付阻力 | P0 |
| 多分镜推故事 | 制作差异化能力，需先定义契约 | P1 |
| 白模推进动画 | 差异化制作能力，需样片和技术方案 | P1/待定义 |
| 完整学习分析和校级报表 | 影响规模化，但不应阻塞第一场销售 | P1 |

## 7. 一句话校验

如果一个页面不能回答以下任一问题，就不应成为 10/22 的主展示页面：

- 学校买了以后谁用？
- 教师如何教？
- 学生练什么？
- 能产出什么作品？
- 企业如何参与和验收？
- 平台如何让这套培训可复制？
