# 短剧实验室分镜工作台需求对齐

> 状态：已对齐，作为后续开发的约束文档
>
> 范围：仅限 VOZEB 的“短剧实验室”，不影响其他创作模块。

## 背景

LocalMiniDrama 的分镜不是“从剧本提取几条文本，再分别放置生成按钮”的列表。它是一条完整的制作工作流：每条分镜同时承载分镜内容、角色/场景/道具关联、参考图、分镜图和分镜视频。资产勾选结果会直接参与后续生成，而不是仅用于展示。

当前 VOZEB 已有的简化 `Shot` 和“分镜 / 镜头生成”分离页面不足以承载这条闭环。本次开发应重构为可持续扩展的分镜实体和同卡片工作台，不在简化结构上继续堆叠临时按钮。

## 本期目标

### 1. 统一分镜工作台

- 将“分镜”和“镜头生成”统一到同一个分镜工作台。
- 每条分镜卡片同时展示和编辑：分镜文本、资产关联、分镜图、分镜视频。
- 保留剧集范围、分镜顺序和当前项目上下文，生成结果归属于对应项目、剧集和分镜。

### 2. AI 拆分镜与真实资产关联

- 从当前剧本生成结构化分镜，而不是只生成一段自由文本。
- 模型返回项目内真实的 `sceneId`、`characterIds`、`propIds`。
- 服务端只接受当前项目中存在的资产 ID；无效 ID 必须被拒绝或明确标记，不能按名称猜测，也不能生成幽灵资产。
- 分镜卡片允许用户手动勾选、取消和修正角色、场景、道具关联。
- 场景为单选，角色和道具支持多选；每项显示资产名称及主参考图缩略图。

### 3. 资产驱动的分镜图与视频

- 已勾选资产的主参考图自动成为该分镜的参考输入。
- 分镜图生成必须由服务端基于分镜内容、项目/剧本上下文、风格、画幅、已绑定资产和后台模板组合提示词。
- 分镜视频生成必须读取该分镜的文本、已绑定资产参考图和分镜图结果；不能继续由前端通用字符串直接拼接后调用。
- 分镜图和分镜视频在同一张卡片内操作、显示状态和结果。
- 支持单镜生成和批量生成，任务需要具备进行中、成功、失败状态及失败重试。

### 4. 结果与历史

- 分镜图、视频结果和生成提示词需要持久化。
- 同一分镜允许保留历史生成结果，并能够恢复或重新生成。
- 页面刷新或重新进入项目后，分镜关联、任务状态和已生成媒体应可恢复。

## 本期明确不做

以下能力不进入第一期，不新增对应的前端配置入口，也不以假按钮占位：

- 分镜数量和视频总时长的 AI 自动规划控件。
- 单张、四宫格、九宫格序列图模式。
- 首帧/尾帧参考图模式及跨镜尾帧衔接。
- 全能分镜模式和 `universal_segment_text`。
- 自动旁白、TTS 以及旁白分轨。
- Excel、SRT 导出。

数据模型应保留后续扩展空间，但第一期不实现上述业务和 UI。

## 关键业务约束

1. 资产关联以 ID 为准，名称只用于展示。
2. 生成链路以服务端为准，前端只提交用户选择和当前编辑内容。
3. 用户手动修改资产勾选后，后续生成必须使用修改后的关联。
4. 重新拆分镜的替换范围默认为当前剧集；必须在替换前提示用户，并避免影响其他剧集。
5. 生成失败不能清空已有成功结果；重试只更新对应任务或新生成版本。
6. 所有改造限定在短剧实验室，不改变其他模块的分镜或素材逻辑。

## 验收标准

- [ ] 从当前剧本能够生成结构化分镜卡片。
- [ ] 每条卡片能够显示并编辑角色、场景、道具勾选及缩略图。
- [ ] 服务端拒绝不属于当前项目的资产 ID。
- [ ] 生成分镜图时实际带入当前卡片已绑定资产参考图。
- [ ] 生成分镜视频时实际读取当前卡片的分镜图、文本和资产参考图。
- [ ] 分镜图和视频在同一张卡片内生成、查看、重试和恢复历史结果。
- [ ] 页面刷新后关联和结果不丢失。
- [ ] 第一阶段页面不出现本文件“本期明确不做”中的配置入口。

## 后续扩展顺序

第一期闭环稳定后，再单独对齐并实现首尾帧、全能分镜、旁白/TTS、批量规划和导出功能。任何扩展不得绕过本期的真实资产 ID 关联和服务端生成链路。
