# 短剧实验室分镜提取需求对齐

> 状态：已被 [短剧实验室分镜工作台需求对齐](/docs/progress/drama-lab-storyboard-workbench-alignment) 取代。本文保留为“先完成 AI 分镜提取”的历史范围记录；后续实现、验收与待测项均以新文档为准。

## 本轮范围

本轮只完善短剧实验室项目工作流的第 3 步“分镜”。入口限定为
`/drama-lab/[id]`，不修改主短剧编辑器 `/drama/[id]`。

交付目标是让用户从当前集剧本一键提取并保存可编辑的结构化分镜，而非以
手工新增分镜为主流程。

## 已确认的业务规则

1. 分镜提取读取当前集剧本以及项目内已经准备好的角色、场景、道具。
2. 文本模型必须返回项目内真实的 `sceneId`、`characterIds`、`propIds`。
3. 服务端对每一条关联重新校验：场景、角色、道具 ID 必须属于当前项目。
   不根据资产名称猜测或映射，也不创建不存在的“幽灵资产”。
4. 任意镜头含非法资产 ID 时，整次提取失败，不保存部分结果。
5. 成功结果替换当前集已有分镜，并持久化到当前集 `shots`，保留其他集分镜。
   若当前集已有分镜，界面先要求用户确认替换。
6. 提取后的每个分镜可以继续手工编辑、删除和补充，资产关联在界面中可见。

## 非本轮范围

- 不迁入 L 的九套完整默认提示词。
- 不实现首帧、关键帧、尾帧提示词。
- 不修改分镜图、图片生成、视频生成及其引用图链路。
- 不修改后台模板的全局化与自定义模板治理。

上述能力将在分镜提取稳定后，以新的需求对齐文档进入下一阶段。

## 验收条件

1. 当前集有剧本、且项目已有资产时，可以通过“从剧本提取分镜”生成分镜列表。
2. 每个分镜显示场景、角色、道具和镜头描述，且引用均来自当前项目资产。
3. 模型返回项目外或不存在的资产 ID 时，接口明确报错且现有分镜不被覆盖。
4. 用户确认重新提取后，当前集旧分镜被新结果原子替换；其他集不受影响。
