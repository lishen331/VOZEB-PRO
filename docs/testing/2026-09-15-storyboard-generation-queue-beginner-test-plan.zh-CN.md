# 故事版生成与排队优化内测计划

> 测试日期：当天填写<br>
> 预计用时：30 分钟<br>
> 测试人员：公司内部测试同事<br>
> 测试环境：填写本次内测环境地址<br>
> 测试账号：使用项目提供的测试账号，不要把密码、Cookie 或 API Key 写入记录

## 一、这次要验证什么

昨天反馈了 4 类问题：

1. 封装的 Skill 可能让图片提示词无法精确控制。
2. 页面内容过多，操作路径不够简单。
3. 商用模型等待较久时，拆分资产、拆分分镜和生成图片容易失败，前端反馈不清楚。
4. 生成按钮缺少比例、画质、时长等参数，过度依赖提示词。

今天只测以下两条主线，不需要全面检查其他页面：

- **故事版生成控制度**：生成图片和视频后打开对应画布，与故事版结果对比。重点看画布是否能看到或复现本轮实际提示词和参数；画布当前没有内置提示词，要记录这种差异。
- **排队和失败反馈**：测试“拆解资产”和“拆解分镜”的等待过程、成功率、失败提示和恢复方式。

## 二、开始前准备

1. 使用 Chrome 或 Edge 打开测试环境地址。
2. 登录测试账号。
3. 准备一段 3～5 句的短故事。建议包含：人物、地点、动作和画面风格。
4. 准备一张可作为参考图的图片；没有参考图时可跳过上传步骤。
5. 打开计时工具或手机秒表。每次点击“生成”“拆解资产”“拆解分镜”时开始计时。
6. 截图时不要包含账号密码、密钥或私人信息。

## 四、测试 A：故事版生成图片

### A1. 进入故事版

1. 登录后进入测试项目。
2. 点击左侧或顶部的 **“故事版”**（如果名称不同，点击能看到分镜列表和画面预览的入口）。
3. 打开一个已有分镜；如果没有分镜，先点击 **“拆解分镜”**，等待本计划的测试 D 完成后再回来。
4. 记下当前分镜编号或名称，后续所有截图都使用同一个分镜。

### A2. 设置参数并生成

1. 点击 **“生成图片”** 或图片生成图标。
2. 在弹出的设置区域逐项检查并填写：
   - 模型；
   - 图片比例或自定义尺寸；
   - 画质；
   - 生成数量（如页面提供）；
   - 参考图（如页面提供）。
3. 在提示词框输入本轮画面要求，例如：“中景，人物站在雨后的街道，电影感，红色雨伞保持在画面右侧”。
4. 点击 **“生成”** 一次，立刻开始计时。
5. 观察页面状态：是否显示排队、生成中、成功或失败；是否显示预计等待、当前阶段或可执行按钮。
6. 生成成功后停止计时，保存结果截图，并记录实际图片尺寸。

### A3. 打开画布对比

1. 在同一条故事版结果上点击 **“打开画布”** 或 **“在画布中查看”**。
2. 确认打开的是当前项目/当前分镜对应的画布，不是空白新画布。
3. 对比故事版和画布中的图片：人物、地点、动作、构图、风格是否一致。
4. 在画布中寻找本轮提示词、模型、比例、画质等信息。
5. 如果画布没有内置提示词，记录“画布未显示提示词”，并检查至少能否看到图片节点的来源、生成参数或结果关联。
6. 返回故事版，确认图片仍存在，刷新页面后再检查一次。

**图片通过标准：**参数可以在生成前点击选择；生成过程中有明确状态；成功后结果与提示词要求基本一致；打开画布不会丢失结果；画布是否显示提示词有明确记录。

## 五、测试 B：故事版生成视频

1. 回到同一分镜，点击 **“生成视频”**。
2. 设置并记录：模型、比例、清晰度、时长、参考图或首帧/尾帧（如页面提供）。
3. 在提示词中写一个可观察动作，例如：“镜头从街道全景缓慢推近，人物抬头看向右侧，雨伞保持红色”。
4. 点击 **“生成”** 一次并开始计时。
5. 记录页面是否依次显示排队、生成中、成功或失败；等待期间按钮是否防止重复提交。
6. 成功后播放视频，检查动作、镜头运动、时长和清晰度是否符合选择值。
7. 点击 **“打开画布”**，确认视频节点属于当前项目/分镜，并与故事版视频对比。
8. 在画布中检查是否有本轮提示词或参数；没有时照实记录，不要推测。
9. 刷新故事版和画布各一次，确认视频没有变成空白或失效链接。

**视频通过标准：**时长、比例、清晰度可以通过界面参数控制；等待状态可见；视频可播放；画布打开后仍关联同一条生成记录；刷新后结果仍在。

## 六、测试 C：拆解资产排队与失败反馈

1. 进入短剧项目的剧本或资产页面。
2. 点击 **“拆解资产”**、**“提取资产”** 或同义按钮一次，并开始计时。
3. 记录页面是否显示：排队中、处理中、已完成、失败或需要检查。
4. 等待任务结束，记录总耗时。等待期间不要连续点击按钮。
5. 成功时检查角色、场景、道具是否出现，刷新后确认仍存在。
6. 失败时先截图，再记录完整错误文案、任务 ID（如有）和页面提供的按钮。
7. 如果有 **“重试”** 或 **“检查状态”**，只点击一次，记录它是继续原任务还是重新创建任务；不要手动重复提交。

**资产排队通过标准：**点击后立即有前端反馈；长时间等待时页面不假死；失败原因可读；用户知道下一步是等待、检查状态还是重试；成功结果刷新后保留。

## 七、测试 D：拆解分镜排队与失败反馈

1. 进入剧本页面，找到 **“拆解分镜”** 或 **“生成分镜”**。
2. 点击一次并开始计时。
3. 记录排队、处理中、完成、失败等状态的出现顺序和大致时间。
4. 成功时打开故事版，确认分镜数量、画面描述和顺序没有明显缺失。
5. 失败时截图并记录错误文案；检查是否可以点击 **“检查状态”** 或 **“重试”**。
6. 若点击重试，确认没有新增一份重复分镜，也没有重复扣费提示（如页面提供计费信息）。

**分镜排队通过标准：**状态变化连续可见；失败后有明确恢复入口；重试不会让同一分镜无限重复；完成后故事版能正常打开。

## 九、提交测试结论

测试结束后用下面格式发到内测群：

```text
结论：通过 / 有问题但可继续 / 阻断
图片控制度：通过 / 不通过，问题是：
视频控制度：通过 / 不通过，问题是：
拆解资产排队：耗时__分__秒，状态反馈：清楚 / 不清楚
拆解分镜排队：耗时__分__秒，状态反馈：清楚 / 不清楚
画布提示词：能看到 / 看不到 / 入口异常
最严重问题：
截图：
```

遇到失败时，先截图和记录文案，再刷新页面验证；不要连续点击生成，也不要为了“测快一点”关闭或强制刷新正在执行的任务。
