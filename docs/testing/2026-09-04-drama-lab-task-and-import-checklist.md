# 短剧实验室任务状态与剧本导入验收清单

## 范围

本次改动只涉及短剧实验室：统一任务状态与取消入口，以及 TXT/MD 剧本导入的编码识别和拖拽导入。普通 Canvas、教师/学生管理、商单算力和平台通用任务不在本次范围内。

## 已实现

- 项目级任务查询：从共享 `generation_tasks` 读取文本、图片、视频、音频和工作流任务，并按短剧项目、成员权限和剧集/分镜坐标过滤。
- 任务面板：显示排队、进行中、完成、失败、取消、进度、当前步骤、剧集和分镜；刷新或重新进入工作台后可恢复。
- 服务端取消：通过任务 ID 执行项目权限校验和类型感知取消，复用已有上游取消、恢复和计费处理；重复取消请求保持幂等。
- 传统文本解码：识别 UTF-8 BOM、无 BOM UTF-8、UTF-16LE、UTF-16BE；UTF-8 校验失败时回退 GB18030，避免替换字符造成乱码。
- 文件导入：文件选择与拖拽共用同一读取、预览、确认和回滚流程，继续校验 TXT/MD 扩展名与 2MB 限制。

## 手工验收

- [ ] 在 `http://127.0.0.1:3002` 短剧工作台启动故事、资产、分镜、分镜图、分镜视频或音频任务，确认左侧任务面板出现记录。
- [ ] 刷新页面、切换剧集，再确认任务记录和状态仍可恢复；任务面板可收起并显示进行中数量。
- [ ] 对一个进行中的任务点击取消，确认前端显示取消请求，服务端状态最终为 `cancelled`，重复点击不会重复扣费或创建任务。
- [ ] 选择 UTF-8、UTF-8 BOM、UTF-16LE、UTF-16BE、GB18030 编码的 TXT/MD 文件，确认预览中文正常。
- [ ] 将 TXT/MD 文件拖入导入区域，确认与文件选择相同地进入预览、确认导入和失败回滚流程。
- [ ] 验证非 TXT/MD 文件、空文件和超过 2MB 文件均被拒绝，并确认文件选择框可再次选择同名文件。
