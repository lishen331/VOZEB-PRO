# 短剧实验室「资产准备」小白测试脚本

> 测试日期：2026-09-14  
> 测试环境：<https://reddetail.gammablue-x.com>  
> 测试项目：`drama-5tNBRUbFvco1HIiF477Or`  
> 测试集数：第 1 集（`ep_1789341997094_0`）  
> 测试账号：请使用项目提供的测试账号登录，不要把密码写入测试记录、截图或提交内容。

## 一、测试目的

验证从进入短剧项目到“资产准备”完成的真实业务闭环：

```text
进入项目 → 打开第1集 → 进入资产准备
→ 角色/场景/道具提取
→ 编辑资产
→ 上传/拖拽参考图
→ AI生图
→ 查看候选图并设置主参考图
→ 加入素材库
→ 画布定位
→ 保存草稿
```

每个按钮都要记录三件事：

1. 点击前页面显示什么；
2. 点击后发生什么；
3. 刷新页面后结果是否仍然保留。

## 二、登录和进入项目

### 1. 登录

1. 打开测试环境地址。
2. 输入测试账号和密码。
3. 勾选“我已阅读并同意服务条款和隐私政策”。
4. 点击“登 录”。

**预期结果：**进入指定短剧项目的第 1 集页面；不应停留在登录页，也不应出现 401/403 错误。

### 2. 顶部按钮说明

| 按钮 | 作用 | 小白验证方式 |
|---|---|---|
| 返回项目大纲 | 回到当前短剧项目的大纲/集数页面 | 点击后应离开当前集工作台 |
| 打开本集画布 | 打开当前集专属画布 | URL 中应带当前 `episodeId` |
| 一键全流程 | 打开剧本、资产、分镜等全流程任务配置 | 只打开配置，不要误点确认生成 |
| 保存草稿 | 保存当前项目修改 | 点击后应提示保存成功或状态更新 |

## 三、进入资产准备

点击顶部步骤 **“2 资产准备”**。

页面应看到三个 Tab：

- `角色`
- `场景`
- `道具`

顶部常见按钮：

| 按钮 | 作用 |
|---|---|
| 一键提取 | 一次提取角色、场景、道具三类资产 |
| 提取角色/提取场景/提取道具 | 只提取当前 Tab 对应的一类资产 |
| 从素材库添加 | 从已有素材库选择图片加入当前项目 |
| 新增角色/新增场景/新增道具 | 手动创建一条资产 |

## 四、角色 Tab 测试

### A. 查看角色卡片

1. 点击“角色” Tab。
2. 检查角色卡片是否显示：
   - 主参考图或“待补主参考图”；
   - 角色名称；
   - 文字描述；
   - AI 生图；
   - 上传；
   - 加入素材库；
   - 画布定位；
   - 影响分镜。
3. 如果有参考图，确认缩略图是完整等比例显示，不应裁掉人物脸部或身体。

### B. 提取角色

1. 点击“提取角色”。
2. 等待按钮结束 loading。
3. 观察是否新增角色卡片。

**预期结果：**

- 有剧本时，返回角色资产；
- 重复提取不应无限重复增加同名角色；
- 失败时出现明确错误提示；
- 刷新后提取出的角色仍存在。

### C. 编辑角色

1. 点击角色卡片上的“编辑设定”。
2. 检查弹窗顺序：
   - 参考图；
   - 名称；
   - 身份/定位；
   - 外貌描述；
   - 简介；
   - 图生提示词；
   - 视觉锚点；
   - 多阶段造型。
3. 检查参考图区域：
   - 无图时，灰色区域可以点击或拖入图片；
   - 有图时显示缩略图；
   - 有图时显示“从参考图提取描述”和“移除参考图”；
   - 不应额外弹出第二个上传窗口；
   - 点击图片不应打开无关的放大预览。
4. 修改名称或描述，点击“保存”。
5. 刷新页面，重新打开该角色。

**预期结果：**修改内容保留，弹窗宽度固定，内容超出时由弹窗内部滚动，不影响页面其他区域。

### D. 参考图上传与拖拽

准备 2 张本地图片。

1. 打开一个角色编辑弹窗。
2. 点击灰色参考图区域，选择 2 张图片。
3. 等待上传结束。
4. 确认弹窗内立刻出现主参考图。
5. 确认同时出现：
   - 从参考图提取描述；
   - 移除参考图。
6. 再次打开弹窗，尝试把 2 张图片同时拖入灰色参考图区域。

**预期结果：**两张图片都被保存到候选参考图，第一张成为主参考图；不需要刷新页面才能看到结果。

### E. 角色 AI 按钮

#### 重新生成提示词

1. 在角色编辑弹窗点击“重新生成提示词”。
2. 等待 loading 结束。
3. 检查“图生提示词”文本框。

**预期结果：**得到可读的最终角色图片提示词，应该包含角色四视图/工业角色参考表布局约束；用户可以手动修改，点击保存后才持久化。

#### 提炼视觉锚点

1. 有参考图时点击“提炼视觉锚点”。
2. 等待 AI 返回。
3. 检查视觉锚点区域。

**预期结果：**返回角色的视觉识别、造型材质、固定色彩和一致性规则；有图时应使用多模态视觉模型。

#### AI 生成造型

1. 点击“AI 生成造型”。
2. 检查多阶段造型区域。

**预期结果：**返回 JSON 数组，包含集数范围和对应造型，例如：

```json
[{"episodeRange":[1,3],"appearance":"日常浅色外套"}]
```

### F. 角色 AI 生图

1. 关闭编辑弹窗。
2. 点击角色卡片“AI 生图”。
3. 等待任务结束。
4. 检查：
   - 是否生成图片；
   - 是否加入候选参考图；
   - 是否保留旧的主参考图；
   - 没有主图时，新图是否自动成为主图。
5. 刷新页面后再次检查。

**预期结果：**角色使用最终提示词和角色参考图合同生成，不应只生成一张无布局约束的普通人物图。

## 五、场景 Tab 测试

### A. 提取和新增

1. 点击“场景” Tab。
2. 点击“提取场景”。
3. 确认生成地点、时间、场景描述。
4. 点击“新增场景”，填写名称/地点、时间、描述并保存。

### B. 模式选择

场景默认是单图。检查场景区域是否有：

```text
生成四宫格场景（默认单图）
```

1. 不勾选时点击 AI 生图。
2. 预期生成一张完整连续场景图，无人物。
3. 勾选四宫格后再点击 AI 生图。
4. 预期使用场景四格合同：
   - 全景建立镜头；
   - 主活动区域；
   - 环境细节；
   - 替代机位。

刷新页面确认模式和结果保留。

## 六、道具 Tab 测试

### A. 提取和新增

1. 点击“道具” Tab。
2. 点击“提取道具”。
3. 确认生成道具名称、类型、描述。
4. 点击“新增道具”，填写名称、类型、描述并保存。

### B. 模式选择

道具默认是单图。检查是否有：

```text
生成四视图道具（默认单图，纯色无缝背景）
```

1. 不勾选时点击 AI 生图。
2. 预期生成一件道具主体，纯色无缝背景，无人物、无手、无环境。
3. 勾选四视图后点击 AI 生图。
4. 预期生成同一道具的：
   - 正面；
   - 侧面；
   - 背面；
   - 材质/结构细节。

## 七、候选参考图和主参考图

1. 对已经有图片的资产，再点击一次“AI 生图”。
2. 确认旧主图不会被自动替换。
3. 在候选参考图中点击另一张。
4. 确认它变成主参考图。
5. 删除非主参考图。
6. 删除主参考图，确认下一张候选图自动成为主图。
7. 刷新页面，确认主图选择保留。

## 八、从素材库添加

1. 点击当前 Tab 的“从素材库添加”。
2. 在弹窗中搜索或浏览素材。
3. 选择一张图片。
4. 确认它加入当前项目对应的角色/场景/道具列表。
5. 确认图片成为该资产参考图。
6. 刷新页面检查是否仍存在。

## 九、画布定位

1. 在资产卡片点击“画布定位”。
2. 确认进入当前集画布，而不是普通画布。
3. 确认 URL 中包含：
   - 当前项目 ID；
   - 当前集 ID；
   - 资产类型；
   - 资产 ID。
4. 返回资产准备页面，确认项目数据没有变化。

## 十、保存和刷新验收

对至少一名角色、一个场景、一个道具分别完成一次修改：

1. 修改描述或提示词。
2. 点击弹窗“保存”。
3. 点击页面顶部“保存草稿”。
4. 刷新浏览器。
5. 重新进入资产准备。

**预期结果：**名称、描述、最终提示词、模式、参考图、主图和候选历史都保留。

## 十一、失败记录模板

| 项目 | 内容 |
|---|---|
| 测试步骤 | 例如：角色 → 编辑设定 → 点击 AI 生图 |
| 实际结果 | 发生了什么 |
| 预期结果 | 应该发生什么 |
| 是否刷新后仍存在 | 是 / 否 |
| 页面截图 | 文件名 |
| 浏览器 Console 错误 | 复制错误文本，不要复制密钥 |
| 任务/日志 ID | 如页面显示则填写 |
| 严重程度 | 阻断 / 严重 / 一般 / 轻微 |

## 十二、测试注意事项

- AI 生图、提示词生成、视觉特征提取会消耗真实模型额度，测试时不要重复无意义点击。
- 点击生成后先等待任务状态，不要连续点击造成重复任务。
- 失败时先截图，再记录错误文本，再刷新验证是否可以恢复。
- 不要把账号密码、API Key、Cookie 写入截图或测试文档。
- L 对比测试应使用相同剧本、相同风格、相同模型和相同参考图，分别记录最终提示词和图片结果。
