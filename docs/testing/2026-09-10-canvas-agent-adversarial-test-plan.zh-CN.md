# Canvas Agent 下一阶段：真实环境逆向与异常流程测试计划

日期：2026-09-10
范围：仅画布右侧 Canvas Agent；不测试 `/create` 主 Agent，不修改短剧实验室。
状态：规划阶段，待分会话输出汇总后执行。

## 目标

在独立测试画布上验证 Canvas Agent 正向、逆向、异常和恢复闭环。所有结论必须绑定真实环境证据，不以模型自述或代码存在代替通过。

## 并行会话分工

### 会话 A：正常流程黑盒测试

- 独立测试画布创建与进入；
- 空选择文本问答；
- 单节点文本编辑；
- 多节点批量编辑；
- 图片引用与视觉理解；
- 混合媒体引用；
- 图片、视频、音频生成；
- 结果节点与引用关系核对；
- 保存 Run ID、任务 ID、截图、SSE 时间线和结果状态。

### 会话 B：异常/逆向流程测试

- 生成中删除目标节点；
- 生成中修改目标节点正文或类型；
- SSE 断开与恢复；
- 刷新、离页、重复进入；
- 重复点击、重复提交；
- 上游失败、超时、部分成功；
- 取消、暂停、继续、重试、重新检查；
- 验证成功结果不丢失、失败结果不伪装成功、不会重复扣费或重复添加节点。

### 会话 C：证据整理与报告审查

- 统一记录 Run ID、任务 ID、时间、模型、渠道和输入媒体；
- 对照中转后台、应用日志、SSE 事件和数据库状态；
- 审查会话 A/B 的结论是否有证据支撑；
- 区分线上通过、线上失败、隔离通过、代码已接入未实测、未接入；
- 汇总最终验收报告，不参与业务修改。

## 执行约束

1. 使用独立测试画布，禁止修改用户业务画布；
2. 每次真实生成前确认模型、渠道、参考媒体和预计成本；
3. 不批量触发高成本视频任务；
4. 每个用例只改变一个变量；
5. 记录开始和结束时间；
6. 失败时保留页面、控制台、服务器和上游证据；
7. 未有完整证据不得标记为通过；
8. 测试期间不修改生产配置和密钥；
9. 发现阻断性问题先记录，不在测试会话中直接修复；
10. 所有报告使用绝对时间（北京时间）。

## 最终报告分级

- P0：数据丢失、错误覆盖、重复扣费、假成功、越权修改；
- P1：结果未回写、恢复失败、取消状态错误、引用关系错误；
- P2：提示、布局、耗时展示或非阻断体验问题。

- Run/任务/上游/数据库对账表；
- 最终验收报告；
- 待修复问题清单和优先级。
