# Agent 续测缺陷修复计划

范围：/create 已复现缺陷；不更改上游额度、渠道用途、短剧实验室和同事未提交文件。

1. 规划失败显式重试：持久化尝试序号参与计费幂等身份；同次重复投递身份不变，成功任务不重新执行。
2. Skill：无显式能力契约的策划类/通用Skill允许文字产物；requiresReference在生成前验证真实引用，并对最终生成任务再次校验，不能靠“等待原图”提示词替代校验。
3. 多模型：一个子任务needs_review不得停止其他已提交任务的结果同步；成功产物继续保存。所有可执行子项结束后才暂停等待确认。
4. UI：待确认和普通暂停区分，展示各子任务状态、解释不应重试创建，提供安全重新检查、取消入口；检查复用原子任务身份，无ID不能重新创建。同步事件需刷新任务与资产，partial_success作为终态。
5. 候选目录：公开保留渠道用途，正式工作台排除练习专用渠道，不改变练习工作台自己的接口与配置。

验证：失败测试先复现，针对性测试/类型/Lint/构建；原线上失败用例仅在部署后重新验证。保留原needs_review子任务，不通过自动退款、创建替代任务或伪造成功绕过。
