## 5. 图一：EasyArt 图片结果已生成但授权媒体读取失败

- **任务**：`f60977d1-7df7-410d-8af9-396661db3746`；模型 `gpt-image-2-c`。
- **发生时间**：任务创建约 11:57（Asia/Shanghai）；上游阶段耗时约 **95.689 秒**，随后进入授权媒体读取失败。
- **关键证据**：EasyArt `https://api.easyart.cc/v1/images/generations` 返回 HTTP 200，request ID `cb4fd143`；我方最终报“上游图片无法通过授权媒体路径读取”，没有结果资产，已退款。
- **真正原因**：HTTP 200 只代表上游生成接口响应，不代表我方已成功读取最终图片。当前任务诊断没有持久化最终图片 URL、HTTP status、Content-Type、字节数，无法进一步证明是 CDN 过期、授权媒体代理失败还是回源失败。
- **当前影响**：用户可能看到生成成功/等待后失败；结果无法追回，任务净扣费为 0。

- **真正原因范围**：请求已到达上游，不是前端网络错误；现有证据不能进一步区分兔子不跟随 307、无法访问 OSS，或不接受跳转/Range。
- **当前影响**：视频生视频/视频参考路径不可用；纯文生视频不受这条故障影响。
