## 3. 关键故障、证据与原因

### P0：图片多渠道绑定/溢出路由错误

- 证据：后端任务诊断中出现真实内部响应 `403 该上游模型未绑定可用逻辑模型`；部分任务先收到上游 429 或 504，自动溢出后落到未绑定模型。
- 影响：`gpt-image-2`、`gpt-image-2-text-to-image`、`gpt-image-2.5-sunburst`、`gpt-image-2-all` 等在齐步/混合窗口出现失败；前端只显示通用错误，掩盖了内部路由原因。
- 建议：冻结逻辑模型→渠道→上游模型绑定校验；路由候选队列在提交前排除未绑定逻辑模型；溢出后返回可解释的渠道不可用原因，并保证扣费仍按用户选中模型。

### P0：EasyArt 图片结果已生成但我方授权媒体读取失败

- 任务：`f60977d1-7df7-410d-8af9-396661db3746`。
- 证据：上游 `https://api.easyart.cc/v1/images/generations` HTTP 200，耗时约 95.689 秒，request ID `cb4fd143`；随后我方授权媒体读取阶段报“上游图片无法通过授权媒体路径读取”，无结果资产，已退款。
- 结论：不能把 HTTP 200 当作用户可用；当前日志没有持久化最终图片 URL/status/content-type，无法追回或证明当时 CDN/媒体代理的具体失败点。
- 建议：保存脱敏 URL host、HTTP 状态、Content-Type、字节数、任务 ID和失败阶段；上游 200 但媒体不可读时自动标记失败并退款，禁止显示成功；与 EasyArt 用 request ID 追查 URL 生命周期。

### P0：兔子视频参考素材无法下载

- 任务：`fba777ad-47e7-418e-90cc-049823a13424`；父视频任务 `69461447-4baf-4906-ab5b-4d06878592c1`。
- 证据：兔子收到真实视频参考 URL 后访问我方媒体接口；我方返回 307 跳转 OSS，兔子随后 HTTP 400「素材地址未返回可下载文件」，request ID `202610200349488872884368268d9d67ZbgdDp4`，平台转为 502。
- 结论：请求确实到达上游，不是前端网络故障；无法从现有证据断定兔子是不跟随 307、无法访问 OSS，还是不接受跳转/Range。
- 建议：向兔子提供 request ID；可选方案是短时直读 OSS URL或同源媒体代理返回 200 `video/mp4`，同时保留鉴权、Range、限流和过期控制。

### P1：上游参数/能力契约不兼容

- ModelBay `gpt-image-2-5-flare`：上游 HTTP 400 `Unknown parameter: response_format`。
- EasyArt 异步图片接口：HTTP 400 `image async only supports response_format=url; use synchronous endpoint for b64_json`。
- 多图文本：真实请求体约 6.8MB，平台 HTTP 413 `请求体过大`；两张图片以 base64 直接嵌入文本请求，不适合当前网关限制。

- 兔子 `gpt-image-2`：一条请求被内容安全策略 HTTP 400 拒绝，属于上游内容策略，不是平台崩溃。
