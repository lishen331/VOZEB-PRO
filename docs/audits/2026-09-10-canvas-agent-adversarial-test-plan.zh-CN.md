# 画布 Agent 异常与逆向流程测试计划

- **范围**：仅普通 Canvas Agent（`/canvas/[id]`），不覆盖主 Agent（`/create`）及短剧实验室。
- **目的**：验证异常发生时不误写、不丢结果、不重复执行，并能够恢复、重试或安全取消。
- **原则**：每条结论必须绑定测试环境、时间、画布 ID、Run ID、任务 ID、截图、浏览器网络记录、服务端日志及最终数据状态；“页面看起来正常”不能替代服务端证据。

## 一、测试前置与基线

1. 使用独立测试画布，创建至少：文本节点 A、图片节点 B、视频节点 C，以及至少一条连线。
2. 使用专门测试账号；记录登录会话、浏览器、测试时间（北京时间）。
3. 每次测试前记录：画布节点/连线 JSON 快照、素材引用、Run 列表、任务列表。
4. 每次测试后记录同一组快照，并比较：节点正文、类型、位置、尺寸、连线、结果节点、引用关系是否变化。
5. 为可能产生真实上游费用的图片/视频用例记录逻辑模型、上游模型、请求 ID、扣费结果；可以使用模拟上游完成控制时，优先模拟验证状态机。

## 二、测试状态与统一判定

| 状态 | 允许的结果 | 禁止的结果 |
|---|---|---|
| 生成中 | 显示唯一运行状态，可取消；原节点可继续编辑 | 重复创建相同 Run、无尽转圈、静默失败 |
| 成功 | 结果只保存一次，可恢复、可定位 | 重复结果、覆盖用户新编辑、幽灵节点 |
| 失败 | 显示失败原因，可重试；保留失败记录 | 假成功、丢失错误、自动重复扣费 |
| 取消 | Run/上游任务最终为取消或明确不可取消 | 取消后迟到结果覆盖新内容 |
| 部分成功 | 展示已成功/失败项，支持针对性重试 | 全部标失败或重复生成成功项 |

## 三、异常/逆向测试矩阵

### A. 生成中修改或删除目标

| 编号 | 场景与步骤 | 预期 | 证据 |
|---|---|---|---|
| A-01 | 发起生成；上游运行中修改目标节点正文 | 迟到结果不得覆盖新正文；结果进入待确认/冲突状态 | 修改前后节点快照、Run 事件、保存响应 |
| A-02 | 发起生成；运行中修改目标节点类型（文本→图片等） | 拒绝按旧目标写入；无类型错写 | 节点版本/更新时间、错误码、日志 |
| A-03 | 发起生成；运行中删除目标节点 | 不创建幽灵恢复节点；结果可在待确认区恢复或明确提示 | 删除操作、Run 最终状态、结果存储记录 |
| A-04 | 运行中删除被引用素材/引用节点 | 不删除素材库文件；任务失败或进入待确认，不得产生失效引用 | 资产 ID、引用关系、对象存储日志 |
| A-05 | 运行中移动/缩放节点 | 结果写入不回滚位置、尺寸及连线 | 前后画布 JSON、更新请求 |

### B. SSE 断开与重连

| 编号 | 场景与步骤 | 预期 | 证据 |
|---|---|---|---|
| B-01 | 生成中断开浏览器网络 10–30 秒后恢复 | 服务端 Run 继续；前端重连后补齐事件，不重复结果 | 浏览器 Network、SSE event id、Run 状态 |
| B-02 | SSE 永久断开，等待上游完成 | 页面明确“连接中断/可刷新”；服务端结果仍持久化 | 服务端 Run、任务和结果记录 |
| B-03 | 重复打开两个相同画布标签页 | 两页可观察同一 Run，不重复创建或写入结果 | 两页事件序列、结果节点数量 |
| B-04 | 收到重复/乱序 SSE 事件 | 状态单调推进，重复事件幂等 | 原始事件序列、最终状态 |

### C. 刷新、离页、重复进入

| 编号 | 场景与步骤 | 预期 | 证据 |
|---|---|---|---|
| C-01 | 生成中刷新页面 | 页面恢复同一 Run 和当前状态，不新建任务 | 刷新前后 Run ID、任务 ID |
| C-02 | 生成中离开画布进入其他页面，再返回 | 结果和阶段可恢复；不会丢失或重复 | 路由时间线、Run/结果快照 |
| C-03 | 完成后关闭页面，稍后重新进入 | 结果仍可见并可定位到目标画布 | 持久化结果、画布 JSON |
| C-04 | 快速重复点击生成/重复提交相同请求 | 服务端去重；最多一个有效任务，或明确多个任务且不互相覆盖 | 请求 ID、幂等键、Run 数量 |
| C-05 | 进入历史已完成 Run | 能看到最终结果和执行状态，不重新调用上游 | 上游请求数、读取接口日志 |

### D. 上游失败、部分成功、重试、取消

| 编号 | 场景与步骤 | 预期 | 证据 |
|---|---|---|---|
| D-01 | 上游立即返回 4xx/5xx | Run 标记失败，展示可理解原因，可重试 | 上游响应（脱敏）、服务端错误链 |
| D-02 | 上游超时 | 前端不无限转圈；服务端最终态明确，重试不重复覆盖 | 超时日志、任务状态时间线 |
| D-03 | 任务结果回调缺失 | 状态进入可恢复/超时失败，不能永远 running | Worker 日志、超时策略 |
| D-04 | 多结果任务中一项成功、一项失败 | 展示部分成功；只重试失败项；成功项不重复扣费/生成 | 子任务 ID、结果资产 ID |
| D-05 | 生成中点击取消 | 前端立即反馈；服务端向上游发取消或记录不可取消；迟到结果不覆盖 | 取消请求、上游状态、最终 Run |
| D-06 | 取消后上游迟到成功 | 结果进入待确认/已取消结果，不自动写入原目标 | 取消时间与回调时间、写入审计 |
| D-07 | 失败后点击重试 | 新 Run/子任务与旧 Run 可区分；旧失败记录保留 | parentRunId、重试次数、任务数量 |
| D-08 | 连续快速点击重试 | 幂等或按钮锁定，不创建重复上游任务 | 请求时间线、上游请求数 |
| D-09 | 取消后刷新/重新进入 | 仍显示取消最终态，不恢复为运行中 | 页面截图、服务端状态 |

## 四、组合场景（高风险）

1. **SSE 断开 + 节点删除 + 上游迟到成功**：不得写幽灵节点，结果必须待确认或可恢复。
2. **刷新 + 重复点击 + 上游超时**：不得创建重复 Run；最终状态可解释。
3. **多标签页一页编辑、一页取消**：编辑页不被静默覆盖；取消状态最终一致。
4. **部分成功 + 运行中删除其中一个目标节点**：成功项可保留，删除项不写回。
5. **任务完成瞬间修改节点**：以服务端目标版本/内容指纹作最终判定，不能靠前端时间顺序猜测。

## 五、每条用例的证据清单

- 测试编号、开始/结束时间、环境 URL、浏览器和账号（账号脱敏）。
- 画布 ID、目标节点 ID、目标节点版本/更新时间。
- Agent Run ID、生成任务 ID、子任务 ID、幂等键。
- SSE 连接建立/断开/重连、事件 ID、阶段顺序及最终事件。
- 前端截图：生成中、失败、取消、部分成功、恢复后。
- Network 请求/响应状态码（密钥和隐私字段脱敏）。
- 服务端应用日志、Worker 日志、上游请求 ID/模型/协议。
- 结果资产 ID、媒体 URL（必要时保存签名 URL 的状态码，不保存密钥）。
- 测试后画布与素材库快照及差异。

## 六、通过门槛

- P0：A-01、A-03、B-01、B-02、C-01、C-02、C-04、D-01、D-02、D-05、D-06 全部通过。
- 任一用例出现幽灵节点、迟到结果覆盖用户编辑、重复扣费/重复结果、永久 running，阶段不得验收通过。
- 每个失败用例必须关联缺陷编号、复现步骤、日志时间范围和最小修复建议。
- 仅有截图无 Run/任务/服务端证据的结果标记为“待证实”，不得标记通过。

## 七、执行分工建议

- **正向/恢复测试会话**：A、C 矩阵及组合场景 1/2。
- **网络与 SSE 会话**：B 矩阵及 SSE 组合场景。
- **上游故障会话**：D 矩阵，优先使用可控模拟响应，再做少量真实扣费验证。
- **审计/报告会话**：统一收集 Run、任务、日志和截图，维护结果表，不修改业务代码。

本计划只定义测试，不包含代码修改；测试完成后将生成“通过/失败/待证实”汇总报告，并附证据索引。
