# 用户运营新增用户弹窗关闭异常修复

## 问题

在管理中心的“用户运营”页面打开“新增用户”后，点击“取消”、关闭按钮或遮罩区域，页面显示 “This page couldn't load”。

## 原因

关闭弹窗会调用 `resetFields()`。gamma-ui 表单兼容层会把未定义的非勾选字段映射为空字符串；“永久积分”字段使用 `InputNumber precision={2}`，其格式化逻辑对该字符串调用 `toFixed()`，抛出运行时异常并进入 Next.js 错误页。

## 方案

让 `InputNumber` 只对真实数字执行精度格式化，其他运行时值按空值渲染；增加空字符串输入回归测试。取消、关闭按钮和遮罩关闭路径共用该防护，不改变表单提交或积分业务逻辑。

## 验收

- 三种关闭方式均留在 `/admin?section=users`，页面不出现错误页。
- `InputNumber` 的数字精度格式化保持不变。
- 相关单元测试、类型检查、ESLint、格式检查通过。
