# 模型连接测试需求对齐（2026-09-08）

## 1. 目标

在管理员的“模型渠道”配置页增加低成本、可重复的单模型连接测试，验证当前模型实际路由是否可用，帮助定位“所有候选渠道均失败”等问题。范围仅限模型渠道与右侧默认模型配置，不改生成业务链路。

## 2. 已确认的交互

### 2.1 左侧模型列表

- 每个模型卡片增加“连接测试”按钮。
- 每个模型独立测试，不增加“批量测试全部模型”。
- 该按钮第一次点击执行测试；测试完成后，按钮区域显示最近一次状态（可用、部分可用、不可用等），不再只显示“连接测试”。
- 用户再次点击状态区域时，打开“连接测试结果”弹窗。
- 弹窗展示最近一次测试结果，包含：模型名、能力、总体状态、响应时间、测试时间、请求 ID、错误摘要，以及该模型绑定渠道的结果（如适用）。
- 弹窗底部右下角提供“重新测试”按钮。点击后在弹窗内重新执行测试并刷新结果。
- 测试中需要明确显示加载状态，避免重复点击。

### 2.2 右侧默认模型区域

- 增加一个“连接测试”按钮。
- 只测试右侧当前已经选中的默认模型（文本、图片、视频、Canvas 图片理解等当前配置项）。
- 不测试列表中的其他模型。
- 不增加批量测试全部默认模型按钮。
- 点击后使用与左侧结果相同的弹窗展示测试结果；弹窗底部右下角仍提供“重新测试”。
- 默认模型更换后，旧测试结果不能冒充新模型状态；应按模型/能力/路由配置进行区分，若配置已变化则显示“未测试”或要求重新测试。

## 3. 状态定义

- **可用**：当前实际路由测试成功。
- **部分可用**：同一逻辑模型绑定多个渠道时，至少一个渠道成功、至少一个失败。
- **不可用**：所有绑定渠道均失败，或没有可用渠道。
- **未测试**：没有成功的测试记录，或当前模型配置已发生变化。

失败原因需要尽量保留可读的原始摘要，例如：

- 无权访问企业专供分组
- 模型不存在
- 协议不兼容
- 不支持该能力
- 上游超时
- 配额/余额不足
- 未配置可用渠道

## 4. 测试边界

- 测试必须走该模型当前实际绑定的渠道、鉴权、协议和上游模型配置，不能只做网络 Ping，也不能只检查模型名称。
- 按模型能力选择最小测试请求：文本、图片理解、图片生成、视频等使用各自对应的真实协议。
- 同一模型存在多个绑定渠道时，测试结果应汇总为总体状态，并保留每个渠道的结果；不要求用户手动逐渠道操作。
- 连接测试应使用最小请求，控制上游成本；不执行完整生成任务。
- 不新增批量测试入口。

## 5. 结果持久化与失效

- 保存最近一次测试结果，供卡片状态和弹窗展示。
- 保存测试时间、响应时间、请求 ID、路由/渠道摘要和错误摘要。
- 当模型、能力、绑定渠道、默认模型选择或相关路由配置改变时，旧结果标记为过期，不继续显示为当前可用。
- 测试结果不能改变默认模型、路由配置或生成任务状态。

## 6. 弹窗结构

标题：连接测试结果

内容：

1. 总体状态（可用/部分可用/不可用/未测试）
2. 模型与能力
3. 当前实际路由/渠道
4. 响应时间、测试时间
5. 请求 ID
6. 渠道明细（成功或失败原因）
7. 原始错误摘要（可复制）

底部右下角：

- 关闭
- 重新测试

## 7. 明确不做

- 不做批量测试所有模型。
- 不做批量测试所有默认能力。
- 不把图片参考图自动判定为视频请求。
- 不改变现有模型选择、路由配置和生成逻辑。
- 不以单纯网络连通作为“模型可用”的结论。

## 8. 验收标准

- 左侧每个模型均可单独测试。
- 首次测试后卡片显示状态；再次点击状态能打开结果弹窗。
- 弹窗可显示成功、部分成功、失败和具体原因。
- 弹窗右下角有“重新测试”，可在原弹窗内刷新结果。
- 右侧按钮只测试当前选中的默认模型。
- 修改模型或路由后，旧状态不会继续误导用户。
- 不产生批量测试请求。
- 测试失败不会影响正常模型配置和其他生成任务。
# 模型连接测试需求对齐（补充修订 2026-09-08）

## 右侧按钮的最终定义

右侧“连接测试”按钮不是只测试一个模型，也不是测试列表中的全部模型。

它测试的是**右侧当前默认模型区域已经选中的全部正式默认能力**：

- 默认文本模型
- Canvas 图片理解模型（visionModel）
- 默认图片模型
- 默认视频模型
- 默认音频模型（如果已配置）

测试范围仅限这些当前正在被正式业务使用的模型；未被选为默认模型的其他模型不参与测试，也不新增“批量测试全部模型”。相同模型/相同路由只测试一次并在多个能力位置复用结果。

左侧模型卡片的“连接测试”仍然只测试当前卡片对应的一个逻辑模型及其已绑定渠道。

## 交互保持不变

- 测试完成后卡片或默认区域显示总体状态。
- 再次点击状态打开结果弹窗。
- 弹窗展示每个被测试模型及渠道明细。
- 弹窗右下角提供“重新测试”。
- 右侧“连接测试”完成后，在同一个弹窗里按能力列出所有当前默认模型结果。
- 不增加测试全部模型按钮，不测试未选中的模型。
