# LocalMiniDrama → VOZEB 短剧实验室对齐开发计划

日期：2026-09-08
范围：仅限 `短剧实验室`，不修改普通短剧、画布、Agent、学校和后台其他模块。

## 1. 背景

LocalMiniDrama（L）已经提供了成熟的剧集管理闭环。当前 VOZEB 短剧实验室（V）虽然已有项目设置、分集、资源导入和项目制作入口，但部分能力仍是简化版，导致用户看到的行为和 L 不一致。

本次开发原则：

- 复用 L 已验证的业务逻辑，不重新发明一套简化流程。
- 保留 V 当前 React/Ant Design UI、路由、权限、服务端持久化和中文术语。
- 所有改动严格限定在短剧实验室。
- 先修复数据和图片真实显示，再补齐交互外观。

## 2. 已确认缺口

### P0：数据与显示正确性

1. 分集编号存在 `第 集`，需要兼容 `episode_number`、`number` 等旧字段并统一标准化。
2. 分集卡片的分镜数量、状态未完整从现有 shots/episode 字段计算。
3. 本剧资源卡片只渲染文字，没有渲染角色、场景、道具参考图。
4. 从素材库导入没有按角色/场景/道具过滤，角色弹窗会出现文本素材和广告提示词素材。
5. 导入资源时没有完整保留 L 的图片地址、本地路径、分类、标签、prompt、来源等信息。

### P1：项目管理交互

1. 项目详情顶部缺少 L 的“进入制作”快捷入口。
2. 风格选择当前是普通文本输入；L 是带分类、缩略图、搜索、选中状态、自定义风格和确认流程的风格选择器。
3. 资源区需要明确区分“全局资源库”和“本剧制作资源”，并使用 V 现有 UI 语言呈现。

### P2：批量导入剧集

1. 当前仅支持手工输入“标题 | 剧本内容”。
2. 缺少 TXT 文件导入。
3. 缺少章节正则配置、每集章节数配置和编码处理。
4. 缺少章节识别预览与用户确认，不能在确认前写入项目。

## 3. 开发方案

### P0 实现

- 新增剧集/资源标准化函数，兼容旧数据字段。
- 资源卡片显示图片，图片缺失时显示明确占位。
- 导入弹窗按 `dramaAssetType` 查询，分别只显示角色、场景或道具素材。
- 导入映射保留图片 URL、远程 URL、存储键、描述、分类、标签和提示词元数据。
- 资源分页不再硬编码只取前 100 条。

### P1 实现

- 顶部增加“进入制作”，默认进入当前项目第一集或最近更新集。
- 增加 L 风格选择器：分类、缩略图、搜索、选中态、自定义风格、清除与确认。
- 迁移 L 的风格缩略图到 V 的 `web/public/style-thumbs`，不改变其他模块。
- 将风格值作为项目 `style` 保存；风格的中文/英文提示词保存到项目 JSON 元数据，兼容现有服务端字段。
- 资源区展示“资源库 / 本剧制作资源”两个分组；全局素材导入后进入当前项目制作资源。

### P2 实现

- 新增批量导入剧集 Modal：
  1. 选择 TXT 文件或粘贴文本；
  2. 配置章节正则；
  3. 设置每集合并章节数；
  4. 解析章节；
  5. 预览集标题、章节和剧本；
  6. 用户确认后原子写入项目。
- 保留现有“标题 | 剧本内容”逐行输入兼容格式。

## 4. 验收标准

### 项目设置

- 顶部同时存在“保存设置”和“进入制作”。
- 风格选择可打开、搜索、选择、清除、自定义并保存。
- 风格选择后刷新页面仍保持。

### 分集

- 所有已有数据都显示正确集数。
- 分镜数量和状态与项目数据一致。
- 顶部“进入制作”能进入合理默认集，分集卡片能进入指定集。

### 资源

- 角色、场景、道具分别只显示对应素材类型。
- 有图片时显示图片，无图片时显示占位。
- 导入后当前项目资源立即出现，刷新后仍存在。
- 全局资源库和本剧制作资源在界面上清晰区分。

### 批量导入

- TXT 文件可读取；章节正则能识别中文数字、阿拉伯数字章节。
- 未确认预览前不会写入项目。
- 确认后集数、标题、剧本内容和编号正确保存。
- 正则错误、未识别章节、空文件都有明确提示。

## 5. 非目标

- 不迁移 L 的 Canvas 实现到本次页面。
- 不修改普通短剧模块。
- 不修改 Agent、学校、IP 库、后台插件市场。
- 不在本次工作中改分镜生成链路和视频生成链路。

## 6. 验证方式

1. 本地 TypeScript、Lint、相关 Vitest。
2. 浏览器登录测试环境，分别验证项目设置、风格、分集、资源导入和 TXT 批量导入。
3. 检查网络请求状态、资源图片 URL、刷新后的持久化结果。
4. 完成后提交 Git，并通过自动部署到测试环境验证。
