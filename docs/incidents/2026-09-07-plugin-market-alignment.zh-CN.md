# 插件市场与全局功能开关需求对齐

日期：2026-09-07

## 目标

在管理员后台的“上游配置”下新增“插件市场”。管理员可全局启停已发布到 VOZEB PRO 的前台功能模块；开关对所有平台用户统一生效。

本需求不是在生产环境上传和执行任意第三方代码。所谓“热插拔”是指：已编译发布的模块通过持久化配置立即启停；未来新增模块仍须通过正常代码发布接入统一注册契约，再由管理员在插件市场控制。

## 纳入第一期的模块

所有当前前台侧边栏功能均纳入插件目录：

| 项目 | `practice`          | 无限练习   | `/practice`   |

| 资产 | `assets`            | 素材       | `/assets`     |

## 启停语义

### 启用

1. 侧边栏、移动端导航、首页快捷入口和跨模块跳转显示。
2. 模块页面可进入。
3. 对应的创建、写入、生成 API 可调用。

### 停用

1. 从侧边栏、移动端导航、快捷入口和跨模块按钮隐藏。
2. 直接访问模块 URL 显示统一的“功能暂未启用”页，不暴露原始页面内容。
3. 服务端拒绝该模块的新建、修改、生成、任务提交等写操作；不能只依赖前端隐藏。
4. 已有项目、素材、提示词、作品、IP、任务和历史数据保留，不删除。
5. 已经在运行的任务不强制取消，允许自然完成；停用后不允许新建任务。后台运维仍可读取记录和任务状态。

## 跨模块守卫

模块状态必须同时作用于跨模块入口：

- `assets` 停用后，Agent、短剧、短剧实验室中的素材库引用入口不可见且服务端不接受相应写入。
- `ip-library` 停用后，教学中心、无限练习等 IP 引用入口不可见。
- `canvas` 停用后，Agent 和短剧实验室中的跳转画布入口隐藏；其他模块不因此整体停用。
- `creative-agent` 停用后，画布、短剧的“交给 Agent”入口隐藏。
- `drama-lab` 停用后，实验室主页、专属素材库与实验室任务提交停用，不影响普通短剧。

第一期不将这些关系实现为会自动级联关闭的硬依赖树。每个模块开关独立，跨模块动作按目标模块状态受保护，避免管理员关闭一个导航入口时意外关闭无关业务。

## 技术设计

1. 建立唯一的内置模块注册表，定义模块 ID、名称、说明、图标、导航分组、根路径、受影响路由和守卫策略。
2. 在全局 `AuthSettings` 增加 `featureModules` 持久化配置，默认所有内置模块启用，兼容存量数据库。
3. 管理员设置 API 和 PostgreSQL/文件存储同时支持该字段；权限归属 `upstream.manage`，每次修改写审计日志。
4. 登录会话仅下发模块启用状态，不下发后台管理信息或密钥。前台导航读取该公开配置。
5. 服务端每个受保护页面和写 API 通过统一模块守卫读取最新全局配置，避免客户端缓存或手动访问 URL 绕过限制。
6. 后台插件市场基于注册表渲染卡片、开关、影响范围、状态和运行中任务提示；不支持删除内置模块或上传可执行代码。

## 验收标准

1. 后台可查看 16 个前台模块并切换任一模块。
2. 关闭模块后，无论桌面或移动端导航、快捷入口还是跨模块入口均不显示。
3. 关闭模块后，直接 URL 访问不能进入原功能；新的写/生成请求被服务端拒绝。
4. 已有数据可在重新启用后恢复访问；运行中任务不被中断。
5. 不影响现有模型渠道、Agent Skills、学校角色权限及平台基础管理功能。
6. 新增一个已发布模块时，只需在注册表登记即可进入插件市场和统一守卫体系。
